# 流程规范：客户反馈收集

## 基本信息

| 属性 | 值 |
|------|-----|
| 流程名称 | 客户反馈收集 |
| 流程编号 | SR-04-02 |
| 所属阶段 | 迭代评审阶段 |
| 执行频率 | 每迭代结束 |
| 参与角色 | 产品经理、客户/Stakeholder |

## 流程目的

系统化收集客户/Stakeholder对产品和迭代的反馈，作为改进依据。

## 执行步骤

### 演示过程中收集
- [ ] 演示每个功能时主动询问反馈
- [ ] 记录即时反应和提问
- [ ] 标注反馈类型

### 演示结束后深度收集
- [ ] 引导讨论：哪些功能符合预期？
- [ ] 引导讨论：哪些功能需要改进？
- [ ] 引导讨论：是否有遗漏的需求？

### 反馈分类整理
- [ ] Bug/缺陷 → 加入缺陷跟踪
- [ ] 功能改进 → 加入Product Backlog
- [ ] 新需求 → 加入Product Backlog

## 输出物

| 输出物 | 说明 |
|--------|------|
| 客户反馈记录 | 结构化的反馈清单 |
