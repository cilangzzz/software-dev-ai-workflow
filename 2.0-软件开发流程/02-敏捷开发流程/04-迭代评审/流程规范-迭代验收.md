# 流程规范：迭代验收

## 基本信息

| 属性 | 值 |
|------|-----|
| 流程名称 | 迭代验收 |
| 流程编号 | SR-04-03 |
| 所属阶段 | 迭代评审阶段 |
| 执行频率 | 每迭代结束 |
| 参与角色 | 产品经理、研发团队、客户/Stakeholder |

## 流程目的

确认本迭代用户故事完成状态，明确验收结论。

## 执行步骤

### 故事逐项验收
- [ ] 逐一确认故事完成状态
- [ ] ✅ 完成：所有AC达成
- [ ] ⚠️ 部分完成：部分AC达成
- [ ] ❌ 未完成：主要AC未达成

### 验收结论确认
- [ ] 统计完成率
- [ ] 分析未完成原因
- [ ] 决定处理方式

### 验收签字
- [ ] 产品经理确认
- [ ] 关键Stakeholder签字

## 输出物

| 输出物 | 说明 |
|--------|------|
| 验收确认记录 | 故事验收状态和签字 |
