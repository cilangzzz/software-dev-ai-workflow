# 迭代评审阶段

## 阶段概述

| 属性 | 值 |
|------|-----|
| 阶段名称 | 迭代评审阶段 |
| 阶段编号 | 04 |
| 主要负责部门 | 产品部、研发部 |
| 前置条件 | 迭代执行阶段完成 |
| 后置阶段 | 迭代回顾阶段 |

## 阶段目标

展示迭代成果，收集客户反馈，确认验收完成。

## 关键活动

| 活动 | 说明 | 负责人 |
|------|------|--------|
| 迭代演示 | 向客户展示完成的功能 | 产品经理 |
| 反馈收集 | 收集客户意见和改进建议 | 产品经理 |
| 迭代验收 | 确认故事完成标准 | 产品经理、研发 |

## 产出物

| 产出物 | 类型 | 必要性 |
|--------|------|--------|
| 演示成果记录 | 文档 | 必须 |
| 迭代评审报告 | 报告 | 必须 |
| 客户反馈记录 | 文档 | 必须 |
| 验收确认记录 | 文档 | 必须 |

## 时间限制

迭代评审会议建议时长：**不超过1小时**
