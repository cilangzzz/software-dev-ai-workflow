# 检查清单：迭代评审就绪

## 必须项（P0）

进入迭代回顾阶段前必须完成：

- [ ] 迭代演示会议已完成
- [ ] 所有承诺故事已明确完成状态
- [ ] 演示成果记录已归档
- [ ] 客户反馈记录已整理完成
- [ ] 验收确认记录已签字确认
- [ ] 迭代评审报告已生成
- [ ] Product Backlog已更新

## 条件项（P1）

- [ ] 关键Stakeholder已参与评审
- [ ] 演示环境稳定可用

## 就绪判定

### 可以进入迭代回顾
1. 所有P0项完成
2. 评审会议时长不超过1小时
3. 验收结论已获得客户确认

### 就绪责任人
**产品经理** - 确认评审阶段就绪状态
