# 流程规范：迭代目标定义

## 基本信息

| 属性 | 值 |
|------|-----|
| 流程名称 | 迭代目标定义 |
| 所属阶段 | 迭代规划阶段 |
| 流程负责人 | 产品负责人 |
| 前置流程 | 需求梳理 |
| 后置流程 | 迭代计划会议 |

## 流程目的

为当前迭代定义清晰、可衡量的目标，为团队提供明确的方向和焦点。

## 触发条件

- 迭代即将开始
- 需求梳理已完成
- Product Backlog已精化

## 输入物

| 输入物 | 来源 | 必要性 |
|--------|------|--------|
| Product Backlog | 项目启动/需求梳理 | 必须 |
| 项目愿景 | 项目启动 | 必须 |
| 产品路线图 | 产品规划 | 建议 |
| 干系人期望 | 干系人 | 建议 |

## 执行步骤

### Step 1: 目标分析

- [ ] 回顾项目愿景和产品路线图
- [ ] 分析当前产品状态
- [ ] 识别关键干系人期望
- [ ] 评估技术债务和改进需求

### Step 2: 候选目标生成

- [ ] 从Product Backlog中识别高优先级主题
- [ ] 考虑业务价值和用户影响
- [ ] 考虑技术可行性和风险
- [ ] 生成2-3个候选迭代目标

### Step 3: 目标评估

- [ ] 评估目标的业务价值
- [ ] 评估目标的技术可行性
- [ ] 评估目标的团队能力匹配度
- [ ] 评估目标的风险因素

### Step 4: 目标确定

- [ ] 选择最佳迭代目标
- [ ] 确保目标符合SMART原则
- [ ] 与团队讨论目标可行性
- [ ] 正式记录迭代目标

### Step 5: 目标沟通

- [ ] 在迭代计划会议上宣布目标
- [ ] 解释目标背景和价值
- [ ] 确保团队理解目标
- [ ] 获取团队承诺

### Step 6: 目标跟踪准备

- [ ] 定义目标完成标准
- [ ] 建立跟踪指标
- [ ] 确定检查点
- [ ] 设置提醒机制

## 质量标准

- 迭代目标清晰、明确
- 目标符合SMART原则
- 目标与用户故事相关联
- 团队理解并认同目标

## 相关Skill

| Skill | 用途 |
|-------|------|
| milestone-tracker | 迭代目标跟踪 |
| requirement-analyzer | 需求分析 |

## 异常处理

| 异常场景 | 处理方式 |
|---------|---------|
| 目标过于宏大 | 拆分为多个迭代的子目标 |
| 目标不清晰 | 与干系人沟通澄清 |
| 团队不认同目标 | 讨论并调整目标 |
| 目标与能力不匹配 | 调整目标范围 |

## SMART原则

| 原则 | 说明 | 示例 |
|------|------|------|
| Specific | 具体：目标明确具体 | 完成用户登录功能 |
| Measurable | 可衡量：有明确的完成标准 | 通过所有登录测试用例 |
| Achievable | 可达成：在团队能力范围内 | 团队评估可完成 |
| Relevant | 相关：与产品目标相关 | 支持用户管理模块 |
| Time-bound | 有时限：在迭代内完成 | 2周迭代内完成 |

## 迭代目标特点

| 特点 | 说明 |
|------|------|
| 聚焦 | 为团队提供清晰焦点 |
| 灵活 | 允许在目标范围内调整具体工作 |
| 可沟通 | 易于向干系人解释迭代成果 |
| 可衡量 | 明确是否达成目标 |

## 迭代目标示例

| 类型 | 示例目标 |
|------|---------|
| 功能型 | 完成用户认证模块，支持登录、注册、找回密码功能 |
| 质量型 | 提升系统稳定性，修复P0/P1缺陷，测试覆盖率达到80% |
| 技术型 | 完成数据库迁移，优化查询性能，响应时间降低50% |
| 探索型 | 完成支付集成技术预研，输出技术方案和原型 |

## 迭代目标与用户故事的关系

| 关系 | 说明 |
|------|------|
| 指导 | 迭代目标指导用户故事选择 |
| 约束 | 用户故事应服务于迭代目标 |
| 灵活 | 在目标范围内可调整具体故事 |
| 优先 | 如果故事不服务于目标，应优先调整 |

## 迭代目标检查点

| 检查点 | 说明 |
|------|------|
| 相关性 | 目标是否与产品愿景相关？ |
| 可达成 | 目标是否在团队能力范围内？ |
| 价值 | 目标是否为用户或业务创造价值？ |
| 紧迫 | 目标是否是当前最重要的？ |
