# 迭代规划阶段

## 阶段概述

| 属性 | 值 |
|------|-----|
| 阶段名称 | 迭代规划阶段 |
| 阶段编号 | 02 |
| 主要负责部门 | 产品部、敏捷团队 |
| 前置条件 | 项目启动阶段完成 |
| 后置阶段 | 迭代执行阶段 |

## 阶段目标

明确迭代目标，完成需求梳理和故事拆分，制定可执行的迭代计划。

## 关键活动

| 活动 | 说明 | 负责人 |
|------|------|--------|
| 需求梳理 | 精化Product Backlog，确保需求清晰 | 产品负责人 |
| 故事拆分 | 将大故事拆分为可执行的小故事 | 敏捷团队 |
| 迭代计划会议 | 确定迭代内容和目标 | 敏捷团队 |
| 迭代目标定义 | 明确迭代交付目标 | 产品负责人 |

## 产出物

| 产出物 | 类型 | 必要性 |
|--------|------|--------|
| Sprint Backlog | 文档 | 必须 |
| 迭代目标 | 文档 | 必须 |
| 用户故事（细化） | 文档 | 必须 |
| Story Point估算 | 文档 | 必须 |

|-------|------|

## 敏捷核心概念

| 概念 | 说明 |
|------|------|
| Sprint Backlog | 迭代待办列表，当前迭代要完成的用户故事集合 |
| User Story | 用户故事，从用户视角描述需求 |
| Story Point | 故事点，估算用户故事相对复杂度的单位 |
| Sprint Goal | 迭代目标，当前迭代要达成的核心目标 |
| Sprint Planning Meeting | 迭代计划会议，时间盒：2-4小时 |
