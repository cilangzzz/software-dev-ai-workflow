# 流程规范：故事验收

## 基本信息

| 属性 | 值 |
|------|-----|
| 流程名称 | 故事验收 |
| 所属阶段 | 迭代执行 |
| 流程负责人 | 产品负责人 |
| 前置流程 | 故事开发完成 |
| 后置流程 | 迭代评审 |

## 流程目的

验证用户故事是否满足验收标准，确保交付质量符合预期。

## 触发条件

- 故事开发完成
- 代码审查通过
- CI构建成功
- 开发自测通过

## 输入物

| 输入物 | 来源 | 必要性 |
|--------|------|--------|
| 用户故事 | 迭代规划 | 必须 |
| 验收标准 | 迭代规划 | 必须 |
| 开发产物 | 故事开发 | 必须 |
| 测试报告 | 持续集成 | 必须 |

## 质量标准

### 验收通过标准

- 所有验收标准满足
- 无阻塞性缺陷
- 无高危缺陷
- 核心功能正常

### 验收失败标准

- 验收标准未满足
- 存在阻塞性缺陷
- 核心功能异常

## 验收结论分类

| 结论 | 说明 | 后续处理 |
|------|------|---------|
| 通过 | 满足所有验收标准 | 移动到完成列 |
| 有条件通过 | 满足核心标准，有小问题 | 记录问题，后续迭代修复 |
| 不通过 | 不满足验收标准 | 退回开发，修复后重新验收 |

## 缺陷分级标准

| 级别 | 说明 | 验收影响 |
|------|------|---------|
| 阻塞 | 功能无法使用 | 验收不通过 |
| 严重 | 核心功能受影响 | 验收不通过 |
| 一般 | 非核心功能问题 | 可有条件通过 |
| 轻微 | 体验问题 | 可通过，记录待修复 |

|------|------|------|
| 开发环境 | 开发自测 | 开发者本地 |
| 测试环境 | 故事验收 | 部署最新版本 |
| 预发布环境 | 迭代验收 | 接近生产环境 |

## 异常处理

| 异常场景 | 处理方式 |
|---------|---------|
| 验收环境不可用 | 联系运维，重新部署 |
| 验收标准有歧义 | 与产品沟通，澄清标准 |
| 发现新问题 | 记录问题，判断是否阻塞验收 |
| 时间冲突 | 重新安排验收时间 |
