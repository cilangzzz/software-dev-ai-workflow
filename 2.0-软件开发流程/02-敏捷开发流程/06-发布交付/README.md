# 发布交付阶段

## 阶段概述

| 属性 | 值 |
|------|-----|
| 阶段名称 | 发布交付阶段 |
| 阶段编号 | 06 |
| 主要负责部门 | 运维部、研发部 |
| 前置条件 | 迭代评审通过 |
| 后置阶段 | 敏捷运维阶段 |

## 阶段目标

持续交付可用增量，确保发布质量和稳定性。

## 关键活动

| 活动 | 说明 | 负责人 |
|------|------|--------|
| 发布规划 | 制定发布内容和时间 | 产品经理 |
| 持续部署 | 自动化部署流程 | 运维工程师 |
| 发布验收 | 确认发布质量 | 运维工程师 |

## 产出物

| 产出物 | 类型 | 必要性 |
|--------|------|--------|
| 发布包 | 包 | 必须 |
| 发布说明 | 文档 | 必须 |
| CI/CD流水线配置 | 配置 | 必须 |
| 发布验收报告 | 报告 | 必须 |

## 时间限制

发布过程应自动化，验收不超过30分钟。

| Skill | 用途 |
|-------|------|
| deploy-analyzer | 发布规划和执行 |
