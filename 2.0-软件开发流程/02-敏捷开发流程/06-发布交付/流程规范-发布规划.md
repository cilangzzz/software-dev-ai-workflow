# 流程规范：发布规划

## 基本信息

| 属性 | 值 |
|------|-----|
| 流程名称 | 发布规划 |
| 流程编号 | AG-06-01 |
| 所属阶段 | 发布交付阶段 |
| 执行频率 | 每迭代结束或里程碑 |
| 参与角色 | 产品经理、运维工程师 |

## 流程目的

确定发布内容、时间和策略，确保有序交付。

## 执行步骤

### 发布内容确定
- [ ] 确定本发布包含的用户故事
- [ ] 确定发布版本号
- [ ] 编写发布说明草稿

### 发布时间规划
- [ ] 确定发布时间窗口
- [ ] 评估发布风险
- [ ] 制定回滚预案

### 发布策略选择
- [ ] 选择发布策略（蓝绿/金丝雀/滚动）
- [ ] 确定发布范围（全量/灰度）
