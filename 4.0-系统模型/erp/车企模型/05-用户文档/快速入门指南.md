## 5分钟快速上手

### 步骤1：登录系统

1. 打开浏览器，访问系统地址
2. 输入用户名和密码
3. 点击"登录"

### 步骤2：熟悉导航

- 左侧：功能模块菜单
- 顶部：用户信息、通知中心
- 中间：工作区域

### 步骤3：查看基础数据

进入"系统管理" → "基础数据"：
- 查看物料列表
- 查看客户列表
- 查看供应商列表

### 步骤4：创建第一个订单

**销售订单示例：**
1. 点击"销售管理" → "销售订单"
2. 点击"新建"
3. 选择客户
4. 添加物料和数量
5. 保存

### 步骤5：查看订单状态

在订单列表中查看订单状态流转：
草稿 → 待审批 → 已审批 → 执行中 → 完成

## 常用快捷键

| 功能 | 快捷键 |
|------|--------|
| 新建 | Ctrl+N |
| 保存 | Ctrl+S |
| 搜索 | Ctrl+F |
| 刷新 | F5 |
