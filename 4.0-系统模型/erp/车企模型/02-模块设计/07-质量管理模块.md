## 1. 模块概述

质量管理模块负责管理企业的质量控制流程，包括来料检验(IQC)、过程检验(IPQC)、成品检验(FQC)、出货检验(OQC)等核心功能。

### 1.1 功能范围

| 功能项 | 功能描述 | 优先级 |
|--------|----------|--------|
| 来料检验(IQC) | 采购物料的入库检验 | P0 |
| 过程检验(IPQC) | 生产过程的巡检 | P0 |
| 成品检验(FQC) | 成品入库前检验 | P0 |
| 出货检验(OQC) | 出货前的最终检验 | P0 |
| 不良处理 | 不合格品的处理流程 | P0 |
| 质量追溯 | 产品质量追溯 | P1 |

### 1.2 与其他模块的关系

- **采购管理模块**：来料检验关联采购订单
- **库存管理模块**：检验结果影响入库
- **生产计划模块**：过程检验关联生产订单
- **销售管理模块**：出货检验关联销售订单

## 2. 数据模型设计

### 2.1 核心数据表

| 表名 | 说明 | 主要字段 |
|------|------|----------|
| qm_inspection_order | 检验单 | id, inspection_no, type, status |
| qm_inspection_item | 检验项 | id, order_id, item_name, result |
| qm_defect | 不良记录 | id, inspection_id, defect_type |

---

## 3. 接口设计（概要）

| 接口 | 方法 | 说明 |
|------|------|------|
| /qm/inspection/create | POST | 创建检验单 |
| /qm/inspection/submit | POST | 提交检验结果 |
| /qm/defect/report | POST | 报告不良 |

---

## 4. 状态流转

```
检验单: 待检 → 检验中 → 合格/不合格 → 处理完成
不良品: 发现 → 分析 → 处理(返工/报废/特采) → 关闭
```
