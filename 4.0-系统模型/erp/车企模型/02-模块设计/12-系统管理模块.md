## 1. 模块概述

系统管理模块负责管理企业信息系统的配置和运维，包括用户管理、权限管理、组织架构、系统配置等核心功能。

### 1.1 功能范围

| 功能项 | 功能描述 | 优先级 |
|--------|----------|--------|
| 用户管理 | 用户账号的增删改查、密码管理 | P0 |
| 角色管理 | 角色定义、权限分配 | P0 |
| 组织架构 | 公司、部门、岗位管理 | P0 |
| 菜单管理 | 系统菜单配置 | P0 |
| 数据权限 | 数据范围权限控制 | P1 |
| 系统配置 | 系统参数配置 | P1 |
| 操作日志 | 用户操作记录查询 | P1 |
| 登录日志 | 登录记录查询 | P1 |

### 1.2 与其他模块的关系

- **所有业务模块**：提供用户、权限、组织架构基础数据
- **多租户支持**：租户隔离、租户配置

---

## 2. 数据模型设计

### 2.1 核心数据表

| 表名 | 说明 | 主要字段 |
|------|------|----------|
| sys_user | 用户表 | id, username, name, status |
| sys_role | 角色表 | id, role_name, role_code |
| sys_menu | 菜单表 | id, menu_name, parent_id, path |
| sys_dept | 部门表 | id, dept_name, parent_id |
| sys_user_role | 用户角色关联 | user_id, role_id |
| sys_role_menu | 角色菜单关联 | role_id, menu_id |

---

## 3. 接口设计（概要）

| 接口 | 方法 | 说明 |
|------|------|------|
| /sys/user/create | POST | 创建用户 |
| /sys/role/create | POST | 创建角色 |
| /sys/menu/list | GET | 获取菜单列表 |
| /sys/dept/tree | GET | 获取组织架构树 |

---

## 4. 状态流转

```
用户状态: 待激活 → 正常 → 禁用 → 删除
角色状态: 正常 → 禁用
```
