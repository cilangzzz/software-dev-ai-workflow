## 1. 模块概述

供应商管理模块负责管理企业与供应商的合作关系，包括供应商准入、供应商评估、供应商协同等核心功能。

### 1.1 功能范围

| 功能项 | 功能描述 | 优先级 |
|--------|----------|--------|
| 供应商档案管理 | 供应商基本信息维护 | P0 |
| 供应商准入管理 | 供应商资质审核、准入流程 | P0 |
| 供应商评估管理 | 供应商绩效评估、分级 | P1 |
| 供应商协同 | 采购协同、交货协同 | P2 |
| 供应商黑名单 | 不合格供应商管理 | P1 |

### 1.2 与其他模块的关系

- **采购管理模块**：供应商选择、采购订单
- **质量管理模块**：供应商质量评估
- **财务管理模块**：供应商付款、对账
- **库存管理模块**：供应商送货入库

## 2. 数据模型设计

### 2.1 核心数据表

| 表名 | 说明 | 主要字段 |
|------|------|----------|
| srm_supplier | 供应商档案 | id, supplier_no, name, status |
| srm_qualification | 供应商资质 | id, supplier_id, cert_type, expire_date |
| srm_evaluation | 供应商评估 | id, supplier_id, score, grade |

---

## 3. 接口设计（概要）

| 接口 | 方法 | 说明 |
|------|------|------|
| /srm/supplier/create | POST | 创建供应商档案 |
| /srm/supplier/approve | POST | 供应商准入审批 |
| /srm/evaluation/submit | POST | 提交供应商评估 |

---

## 4. 状态流转

```
供应商状态: 待审核 → 已准入 → 合作中 → 限制合作 → 黑名单
评估流程: 评估计划 → 数据采集 → 评分 → 定级 → 公示
```
