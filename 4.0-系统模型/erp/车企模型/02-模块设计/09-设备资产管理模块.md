## 1. 模块概述

设备资产管理模块负责管理企业的设备资产全生命周期，包括设备台账、设备维护、设备保养、设备报修等核心功能。

### 1.1 功能范围

| 功能项 | 功能描述 | 优先级 |
|--------|----------|--------|
| 设备台账管理 | 设备基本信息、技术参数 | P0 |
| 设备维护管理 | 设备维修、保养计划 | P0 |
| 设备点检管理 | 设备日常点检 | P0 |
| 备件管理 | 备品备件库存管理 | P1 |
| 设备故障分析 | 故障统计、分析 | P1 |
| 设备折旧 | 资产折旧计算 | P1 |

### 1.2 与其他模块的关系

- **生产计划模块**：设备可用性影响生产排程
- **采购管理模块**：备件采购
- **财务管理模块**：资产折旧、维修费用
- **MES系统**：设备状态实时监控

## 2. 数据模型设计

### 2.1 核心数据表

| 表名 | 说明 | 主要字段 |
|------|------|----------|
| eam_equipment | 设备台账 | id, equipment_no, name, status |
| eam_maintenance_plan | 维护计划 | id, equipment_id, plan_date |
| eam_work_order | 维修工单 | id, order_no, type, status |

---

## 3. 接口设计（概要）

| 接口 | 方法 | 说明 |
|------|------|------|
| /eam/equipment/create | POST | 创建设备台账 |
| /eam/maintenance/plan | POST | 创建维护计划 |
| /eam/work-order/create | POST | 创建维修工单 |

---

## 4. 状态流转

```
维修工单: 报修 → 派工 → 维修中 → 验收 → 完成
设备状态: 运行 → 待机 → 维护中 → 故障 → 报废
```
