## 1. 模块概述

生产计划模块负责制定和管理企业的生产计划，包括主生产计划(MPS)、物料需求计划(MRP)、能力需求计划等核心功能。

### 1.1 功能范围

| 功能项 | 功能描述 | 优先级 |
|--------|----------|--------|
| 主生产计划(MPS) | 制定主生产计划 | P0 |
| 物料需求计划(MRP) | 计算物料需求 | P0 |
| 能力需求计划 | 分析生产能力 | P1 |
| 生产订单管理 | 生产订单的创建、下达、执行 | P0 |
| 排程管理 | 生产作业排程 | P1 |

### 1.2 与其他模块的关系

- **销售管理模块**：销售订单作为生产计划输入
- **采购管理模块**：MRP输出采购需求
- **库存管理模块**：物料可用性检查
- **MES系统**：生产订单下发到MES执行

## 2. 数据模型设计

### 2.1 核心数据表

| 表名 | 说明 | 主要字段 |
|------|------|----------|
| pp_mps | 主生产计划 | id, plan_no, product_id, qty, date |
| pp_mrp | 物料需求计划 | id, plan_id, material_id, req_qty |
| pp_production_order | 生产订单 | id, order_no, product_id, status |

---

## 3. 接口设计（概要）

| 接口 | 方法 | 说明 |
|------|------|------|
| /pp/mps/create | POST | 创建主生产计划 |
| /pp/mrp/run | POST | 运行MRP计算 |
| /pp/production-order/create | POST | 创建生产订单 |

---

## 4. 状态流转

```
生产订单: 草稿 → 计划中 → 已下达 → 生产中 → 完工 → 关闭
```
