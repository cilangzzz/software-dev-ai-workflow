## 一、系统概述

VCP语音社区系统是一款支持用户创建社区、频道分类、多人语音房间的语音社交平台，类似Discord/YY语音。

### 1.1 核心功能

| 功能 | 说明 |
|------|------|
| 用户管理 | 注册登录、资料管理、好友系统 |
| 服务器管理 | 创建社区、邀请成员、角色权限 |
| 频道管理 | 文字频道、语音频道、分类管理 |
| 语音房间 | 多人语音、麦控、发言高亮 |
| 文字消息 | 消息收发、@提及、附件、表情反应 |

## 二、登录与注册

### 2.1 注册账号

1. 打开VCP应用
2. 点击"注册"
3. 输入用户名、邮箱、密码
4. 验证邮箱
5. 完成注册

### 2.2 登录系统

1. 输入账号密码
2. 点击登录
3. 进入主界面
