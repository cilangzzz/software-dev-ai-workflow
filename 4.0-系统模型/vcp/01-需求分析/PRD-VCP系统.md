## 1. 产品概述

### 1.1 产品定位

VCP（Voice Chat Platform）是一款语音社区平台，参考YY语音、Discord等产品，面向需要多人语音交流的社区用户，提供创建社区、频道分类、多人语音房间等核心功能。

### 1.2 目标用户

| 用户群体 | 需求描述 |
|----------|----------|
| 游戏玩家 | 组队游戏时的实时语音沟通 |
| 兴趣社区 | 基于共同兴趣的语音交流社区 |
| 企业团队 | 远程团队的语音会议和协作 |
| 教育培训 | 在线课程的语音互动 |

### 1.3 核心价值

- **低延迟语音**：音频延迟 < 200ms，保障实时沟通体验
- **社区化管理**：服务器-频道-房间的层级结构，灵活组织
- **权限精细控制**：多层级角色权限体系
- **跨平台支持**：桌面端优先，后续支持Web和移动端

## 2. 功能范围

### 2.1 功能模块清单

| 序号 | 模块名称 | 代码 | 优先级 | 说明 |
|------|----------|------|--------|------|
| 1 | 用户模块 | USR | P0 | 注册登录、资料、在线状态、好友 |
| 2 | 服务器/社区模块 | SVC | P0 | 创建社区、邀请、成员管理、角色权限 |
| 3 | 频道模块 | CHN | P0 | 分类管理、文字频道、语音频道 |
| 4 | 语音房间模块 | VCR | P0 | 多人语音、麦控、发言人高亮 |
| 5 | 文字消息模块 | MSG | P0 | 实时消息、历史搜索、@提及、文件发送 |
| 6 | 通知模块 | NTF | P1 | 系统通知、@通知、推送、偏好设置 |
| 7 | 管理审核模块 | MOD | P1 | 踢人/封禁、消息审核、举报、敏感词 |

### 2.2 MVP范围（Phase 1-3）

- 用户模块：注册登录、资料管理、在线状态
- 服务器模块：创建/加入服务器、成员管理、角色权限
- 频道模块：分类管理、文字/语音频道
- 语音房间模块：多人语音通话（核心功能）

## 3. 详细功能需求

### 3.1 用户模块

#### 3.1.1 用户注册

| 需求项 | 描述 |
|--------|------|
| 功能描述 | 用户通过手机号或邮箱注册账号 |
| 输入 | 手机号/邮箱、验证码、用户名、密码 |
| 输出 | 注册成功，自动登录 |
| 业务规则 | 同一手机号/邮箱只能注册一个账号；用户名2-20字符；密码8-32字符，需包含字母和数字 |

#### 3.1.2 用户登录

| 需求项 | 描述 |
|--------|------|
| 功能描述 | 用户通过账号密码或OAuth登录 |
| 输入 | 用户名/手机号/邮箱 + 密码 |
| 输出 | JWT Token，用户信息 |
| 业务规则 | 连续5次密码错误，账号锁定15分钟；Token有效期7天 |

#### 3.1.3 在线状态管理

| 状态 | 说明 |
|------|------|
| 在线（Online） | 正在使用 |
| 离开（Away） | 暂时离开 |
| 请勿打扰（DND） | 不接收通知 |
| 隐身（Invisible） | 显示为离线 |

#### 3.1.4 好友系统

- 搜索用户（通过用户名/ID）
- 发送/接受/拒绝好友请求
- 删除好友
- 好友列表展示（按在线状态分组）

### 3.2 服务器模块

#### 3.2.1 创建服务器

| 需求项 | 描述 |
|--------|------|
| 功能描述 | 用户创建自己的社区服务器 |
| 输入 | 服务器名称、图标、描述、区域 |
| 输出 | 服务器创建成功，创建者成为Owner |
| 业务规则 | 服务器名称2-100字符；每个用户最多创建10个服务器 |

#### 3.2.2 角色与权限

**默认角色：**
- Owner（拥有者）- 拥有所有权限
- Admin（管理员）- 拥有大部分管理权限
- Member（成员）- 基本使用权限

**核心权限：**
| 权限 | 说明 |
|------|------|
| MANAGE_SERVER | 管理服务器设置 |
| MANAGE_CHANNELS | 创建/编辑/删除频道 |
| MANAGE_ROLES | 创建/编辑/删除角色 |
| MANAGE_MEMBERS | 踢出/封禁成员 |
| SEND_MESSAGES | 发送文字消息 |
| CONNECT_VOICE | 连接语音频道 |
| SPEAK | 在语音中说话 |

### 3.3 频道模块

#### 3.3.1 频道类型

| 类型 | 说明 |
|------|------|
| 文字频道 | 实时文字消息交流 |
| 语音频道 | 多人语音房间入口 |

#### 3.3.2 频道分类

- 分类用于组织频道
- 支持拖拽排序
- 可折叠/展开

### 3.4 语音房间模块

#### 3.4.1 多人语音通话

| 需求项 | 描述 |
|--------|------|
| 技术架构 | WebRTC SFU架构 |
| 最大人数 | 20人（后续优化扩大） |
| 音频编码 | Opus |
| 采样率 | 支持48kHz |
| 音频延迟 | < 200ms |
| 音频处理 | AGC、AEC、ANS |

#### 3.4.2 麦克风/扬声器控制

- 自我静音/闭麦
- 管理员静音他人
- 音量调节

### 3.5 文字消息模块

#### 3.5.1 消息类型

| 类型 | 说明 |
|------|------|
| TEXT | 纯文本消息 |
| IMAGE | 图片消息 |
| FILE | 文件消息 |
| SYSTEM | 系统消息 |

#### 3.5.2 消息功能

- 消息发送/接收（实时推送）
- 消息历史与搜索
- @提及（用户/角色/全体）
- 引用回复
- 消息编辑/删除
- Emoji表情反应

## 4. 非功能需求

### 4.1 性能需求

| 指标 | 目标值 |
|------|--------|
| 语音延迟 | < 200ms |
| 消息推送延迟 | < 500ms |
| 单语音房间人数 | 20人（初始） |
| 支持在线用户数 | 待定 |

### 4.2 可用性需求

| 指标 | 目标值 |
|------|--------|
| 系统可用性 | 99.9% |
| 故障恢复时间 | < 30分钟 |

### 4.3 安全需求

- 密码加密存储
- JWT Token认证
- HTTPS加密传输
- 敏感词过滤
