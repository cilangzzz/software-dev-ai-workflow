# 项目管理阶段

## 阶段概述

| 属性 | 值 |
|------|-----|
| 阶段名称 | 项目管理阶段 |
| 阶段编号 | 10 |
| 主要负责部门 | 项目管理部 |
| 前置条件 | 项目启动 |
| 后置阶段 | 项目收尾 |

## 阶段目标

全程把控项目进度、资源、风险，确保项目按计划交付。

## 关键活动

| 活动 | 说明 | 负责人 |
|------|------|--------|
| 项目规划 | 制定项目计划、里程碑 | 项目经理 |
| 进度跟踪 | 监控项目进度、偏差分析 | 项目经理 |
| 资源管理 | 分配和协调项目资源 | 项目经理 |
| 风险管理 | 识别、评估、应对风险 | 项目经理 |
| 沟通协调 | 项目内外沟通协调 | 项目经理 |

| 会议记录 | 文档 | 必须 |

## 执行时机

项目管理阶段贯穿全流程：
- 项目启动：制定项目计划
- 各阶段：进度跟踪、风险管理
- 阶段交接：质量门控评审
- 项目收尾：项目复盘

| Skill | 用途 |
|-------|------|
| project-status | 项目状态跟踪 |
| gate-check | 质量门控检查 |

## 协作关系

### 输入来源
- 各阶段产出物（进度、问题、风险）
- 项目需求（需求阶段）
- 变更请求（各阶段）

### 输出去向
- 项目计划 → 各阶段（执行依据）
- 进度报告 → 管理层（决策依据）
- 风险报告 → 各阶段（风险预警）
