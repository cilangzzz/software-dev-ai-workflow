# 检查清单：迭代回顾就绪

## 检查概要

| 属性 | 值 |
|------|-----|
| 阶段 | 迭代回顾 |
| 目标阶段 | 下一迭代规划/发布交付 |
| 检查目的 | 确认迭代回顾阶段已完成，团队已做好进入下一阶段的准备 |

## 必须项 - 全部满足才能进入下一阶段

### 回顾会议维度

- [ ] 回顾会议已召开
- [ ] 全体团队成员参与
- [ ] 回顾报告已产出
- [ ] 上迭代改进项已检查

### 改进项维度

- [ ] 改进项已识别和记录
- [ ] 改进项已分类和优先级排序
- [ ] 改进项列表已更新
- [ ] 高优先级改进项数量可控（≤3个）

### Action Items维度

- [ ] Action Items已制定
- [ ] Action Items符合SMART原则
- [ ] 负责人已确认
- [ ] 截止日期已确定

### 跟踪机制维度

- [ ] Action Items已纳入跟踪系统
- [ ] 跟进方式已确定
- [ ] 验证时间已安排

## 条件项 - 根据项目类型选择性满足

### 高成熟度团队

- [ ] 改进效果评估已完成
- [ ] 团队满意度已记录
- [ ] 度量数据已分析

### 新团队/低成熟度

- [ ] Scrum Master指导已确认
- [ ] 改进措施可行性已评估
- [ ] 资源需求已确认

### 发布迭代

- [ ] 发布相关改进项已识别
- [ ] 发布准备度已评估
- [ ] 发布风险已识别

## 建议项 - 最佳实践建议

- [ ] 改进项可视化看板已更新
- [ ] 团队改进氛围良好
- [ ] 无遗留阻塞问题
- [ ] 历史改进项完成率≥80%
