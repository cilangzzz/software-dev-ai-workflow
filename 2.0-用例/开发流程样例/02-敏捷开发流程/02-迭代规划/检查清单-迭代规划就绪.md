# 检查清单：迭代规划就绪

## 检查概要

| 属性 | 值 |
|------|-----|
| 阶段 | 迭代规划阶段 |
| 目标阶段 | 迭代执行阶段 |

## 必须项 - 全部满足才能进入下一阶段

### 目标维度

- [ ] 迭代目标（Sprint Goal）已定义
- [ ] 迭代目标符合SMART原则
- [ ] 团队理解并认同迭代目标
- [ ] 迭代目标已记录

### Backlog维度

- [ ] Sprint Backlog已创建
- [ ] Sprint Backlog工作量不超过团队速率
- [ ] 用户故事符合INVEST原则
- [ ] 用户故事有明确的验收标准
- [ ] Story Point估算已完成

### 任务维度

- [ ] 用户故事已拆分为任务
- [ ] 任务有明确的负责人
- [ ] 任务工时估算合理
- [ ] 任务依赖关系已识别

### 承诺维度

- [ ] 团队已承诺迭代目标
- [ ] 团队容量已确认
- [ ] 迭代日历已确认（考虑假期等）
- [ ] 阻塞风险已识别

## 条件项 - 根据项目类型选择性满足

### 复杂项目

- [ ] 技术依赖已确认
- [ ] 跨团队协调已安排
- [ ] 关键路径已识别

### 新团队

- [ ] 迭代流程已培训
- [ ] 工具使用已培训
- [ ] 团队磨合已完成

### 远程团队

- [ ] 远程协作工具已准备
- [ ] 时区重叠已确认
- [ ] 异步沟通机制已建立

## 建议项 - 最佳实践建议

- [ ] 每日站会时间已确定（时间盒：15分钟）
- [ ] 迭代评审时间已预定
- [ ] 迭代回顾时间已预定
- [ ] 看板/任务板已设置
