# 流程规范：快速响应

## 基本信息

| 属性 | 值 |
|------|-----|
| 流程名称 | 快速响应 |
| 流程编号 | AG-07-02 |
| 所属阶段 | 敏捷运维阶段 |
| 执行频率 | 按需触发 |
| 参与角色 | 运维工程师、研发团队 |

## 流程目的

快速处理运维事件，最小化影响范围。

## 执行步骤

### 事件分级
- [ ] P1: 重大故障，影响核心业务
- [ ] P2: 中等故障，影响部分功能
- [ ] P3: 小问题，不影响用户

### 快速处理
- [ ] 立即评估影响范围
- [ ] 启用应急预案（如回滚）
- [ ] 通知相关团队协助
- [ ] 执行修复操作

### 记录和复盘
- [ ] 记录事件详情和处理过程
- [ ] 定期复盘改进
