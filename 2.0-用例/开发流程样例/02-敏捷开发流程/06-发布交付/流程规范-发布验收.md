# 流程规范：发布验收

## 基本信息

| 属性 | 值 |
|------|-----|
| 流程名称 | 发布验收 |
| 流程编号 | AG-06-03 |
| 所属阶段 | 发布交付阶段 |
| 执行频率 | 每次发布后 |
| 时间限制 | 不超过30分钟 |
| 参与角色 | 运维工程师、产品经理 |

## 流程目的

验证发布成功，确保系统正常运行。

## 执行步骤

### 发布后验证
- [ ] 服务健康检查
- [ ] 核心功能验证
- [ ] 监控指标检查
- [ ] 日志错误检查

### 用户验收
- [ ] 关键用户验证核心功能
- [ ] 收集发布后反馈
- [ ] 确认发布成功

## 输出物

| 输出物 | 说明 |
|--------|------|
| 发布验收报告 | 发布验证结果 |
