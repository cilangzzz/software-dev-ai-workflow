# 迭代执行

## 阶段概述

| 属性 | 值 |
|------|-----|
| 阶段名称 | 迭代执行 |
| 阶段编号 | 03 |
| 主要负责部门 | 研发部 |
| 前置条件 | 迭代规划完成 |
| 后置阶段 | 迭代评审 |

## 阶段目标

在迭代周期内高效完成用户故事开发，确保代码质量和团队协作顺畅。

## 关键活动

| 活动 | 说明 | 负责人 |
|------|------|--------|
| 每日站会 | 15分钟同步进展和阻碍 | 全体成员 |
| 故事开发 | 完成用户故事开发 | 研发工程师 |
| 持续集成 | 代码集成和自动化构建 | 研发工程师 |
| 故事验收 | 验证故事完成标准 | 产品负责人 |

## 产出物

## 敏捷实践要点

### 每日站会三问

1. 昨天完成了什么？
2. 今天计划做什么？
3. 有什么阻碍？

### 任务看板管理

- **待办(To Do)**: 迭代待开发任务
- **进行中(In Progress)**: 正在开发任务
- **完成(Done)**: 已完成任务

### 燃尽图跟踪

- 每日更新剩余工作量
- 监控迭代进度
- 及时发现风险

## 协作接口

### 输入
- 迭代计划（来自迭代规划）
- 用户故事（来自迭代规划）
- 验收标准（来自迭代规划）

### 输出
- 可演示功能 → 迭代评审
- 燃尽图数据 → 迭代评审
- 完成故事 → 迭代评审
