# 项目启动阶段

## 阶段概述

| 属性 | 值 |
|------|-----|
| 阶段名称 | 项目启动阶段 |
| 阶段编号 | 01 |
| 主要负责部门 | 项目管理部 |
| 前置条件 | 商业立项已批准 |
| 后置阶段 | 迭代规划阶段 |

## 阶段目标

完成敏捷项目立项，组建敏捷团队，为后续迭代开发做好准备。

## 关键活动

| 活动 | 说明 | 负责人 |
|------|------|--------|
| 敏捷项目立项 | 确定项目愿景、范围、约束 | 产品负责人 |
| 敏捷团队组建 | 组建跨职能敏捷团队 | 敏捷教练/项目经理 |
| Sprint0准备 | 初始化项目环境、创建Product Backlog | 敏捷团队 |

## 产出物

| 产出物 | 类型 | 必要性 |
|--------|------|--------|
| 项目愿景文档 | 文档 | 必须 |
| Product Backlog | 文档 | 必须 |
| 敏捷团队章程 | 文档 | 必须 |
| Definition of Done | 文档 | 必须 |
| 工作协议 | 文档 | 建议 |

## 敏捷核心概念

| 概念 | 说明 |
|------|------|
| Product Backlog | 产品待办列表，按优先级排序的需求列表 |
| Sprint | 迭代周期，通常1-4周 |
| Sprint 0 | 初始化Sprint，用于环境准备和团队磨合 |
| Definition of Done | 完成定义，明确"完成"的标准 |
