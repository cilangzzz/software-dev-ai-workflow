## 产出物分类

按类型分类：
- **图表类**: 架构图、流程图、ER图、类图、时序图、状态图、原型图、数据血缘图
- **文档类**: PRD、技术方案、设计文档、用户手册、运维手册、安全报告、数据报告
- **报告类**: 测试报告、验收报告、复盘报告、进度报告、质量报告
- **计划类**: 项目计划、迭代计划、发布计划
- **清单矩阵类**: 需求追溯矩阵、检查清单、风险登记表、产出物清单

## 使用指南

1. **查找产出物**: 确定所属流程 → 查阅对应产出物清单 → 找到产出物定义
2. **确认必要性**: 查看优先级(P0/P1/P2)判断产出物必要性
3. **找到相关Skill**: 查阅映射表找到对应的生成Skill
4. **验证质量**: 查看质量门控检查项确认产出物质量
