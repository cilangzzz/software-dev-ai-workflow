# 软件开发全流程工作流文档

## 概述

本文档定义了软件开发全流程的8个阶段工作流，每个阶段都有独立的技能文件和工作流脚本。工作流支持通过Skill命令或Workflow工具调用。

## 阶段详细说明

### 阶段1：需求分析阶段

**功能描述**：
- 多Agent并行爬取用户需求文档相关资料（**禁止Mock数据**）
- 调用产品技能进行需求调研
- 产出需求分析文档（PRD框架、用户故事、澄清问题清单）

**核心技能**：
- [requirement-analyzer-v2](../1.0-软件开发流程角色agent模型/产品/skill/requirement-analyzer-v2.skill.md)
- [user-story-generator](../1.0-软件开发流程角色agent模型/产品/skill/user-story-generator.skill.md)

**输入参数**：
- `project_name`：项目名称（必填）
- `requirement_description`：用户需求描述（必填）
- `output_dir`：输出目录（默认：`F:\sandbox\workflow\2.0-用例\项目管理样例\02-开发库\00-需求分析阶段`）
- `skill_dir`：产品技能目录（默认：`F:\sandbox\workflow\1.0-软件开发流程角色agent模型\产品`）

**调用示例**：
```bash
/stage-01 --project_name "HIS系统" --requirement_description "实现医院门诊管理、住院管理、药品管理功能"
```

---

### 阶段2：需求开发阶段

**功能描述**：
- 阅读需求分析文档，深度理解需求
- 调用产品技能产出功能点清单
- 产出业务需求文档（BRD）

**核心技能**：
- [user-story-generator](../1.0-软件开发流程角色agent模型/产品/skill/user-story-generator.skill.md)
- [acceptance-criteria-writer](../1.0-软件开发流程角色agent模型/产品/skill/acceptance-criteria-writer.skill.md)

**输入参数**：
- `project_name`：项目名称（必填）
- `requirement_analysis_dir`：需求分析文档目录（必填）
- `output_dir`：输出目录（默认：`F:\sandbox\workflow\2.0-用例\项目管理样例\02-开发库\01-需求开发`）
- `skill_dir`：产品技能目录（默认：`F:\sandbox\workflow\1.0-软件开发流程角色agent模型\产品`）

**调用示例**：
```bash
/stage-02 --project_name "HIS系统" --requirement_analysis_dir "F:\sandbox\workflow\2.0-用例\项目管理样例\02-开发库\00-需求分析阶段"
```

---

### 阶段3：需求理解阶段

**功能描述**：
- 根据业务需求和功能点文档
- 调用产品技能生成原型图、业务流程图
- 产出详细描述文档（**按模块/子模块/功能点分类组织**）

**核心技能**：
- 原型设计、流程设计技能

**输入参数**：
- `project_name`：项目名称（必填）
- `requirement_docs_dir`：需求文档目录（必填）
- `output_dir`：输出目录（默认：`F:\sandbox\workflow\2.0-用例\项目管理样例\02-开发库\02-需求理解`）
- `skill_dir`：产品技能目录（默认：`F:\sandbox\workflow\1.0-软件开发流程角色agent模型\产品`）

**调用示例**：
```bash
/stage-03 --project_name "HIS系统" --requirement_docs_dir "F:\sandbox\workflow\2.0-用例\项目管理样例\02-开发库\01-需求开发"
```

---

### 阶段4：系统设计阶段

**功能描述**：
- 结合需求文档和网络资料（**禁止Mock数据**）
- 生成系统需求文档
- 包含访问人数、数据增量等系统指标

**核心技能**：
- [system-architect](../1.0-软件开发流程角色agent模型/研发/skill/architect/system-architect.skill.md)

**输入参数**：
- `project_name`：项目名称（必填）
- `requirement_docs_dir`：需求文档目录（必填）
- `output_dir`：输出目录（默认：`F:\sandbox\workflow\2.0-用例\项目管理样例\02-开发库\03-系统设计`）
- `existing_framework`：已有框架描述（可选）

**调用示例**：
```bash
/stage-04 --project_name "HIS系统" --requirement_docs_dir "F:\sandbox\workflow\2.0-用例\项目管理样例\02-开发库\02-需求理解"
```

---

### 阶段5：概要设计阶段

**功能描述**：
- 根据业务需求调用研发技能
- 生成业务架构设计（C4模型）
- 生成数据库设计（表结构、索引、ER图）

**核心技能**：
- [system-architect](../1.0-软件开发流程角色agent模型/研发/skill/architect/system-architect.skill.md)
- [db-designer-java](../1.0-软件开发流程角色agent模型/研发/skill/design/db-designer-java.skill.md)
- [data-model-designer](../1.0-软件开发流程角色agent模型/研发/skill/design/data-model-designer.skill.md)

**输入参数**：
- `project_name`：项目名称（必填）
- `requirement_docs_dir`：需求文档目录（必填）
- `system_design_dir`：系统设计文档目录（必填）
- `output_dir`：输出目录（默认：`F:\sandbox\workflow\2.0-用例\项目管理样例\02-开发库\04-概要设计`）
- `skill_dir`：研发技能目录（默认：`F:\sandbox\workflow\1.0-软件开发流程角色agent模型\研发`）

**调用示例**：
```bash
/stage-05 --project_name "HIS系统" --requirement_docs_dir "F:\sandbox\workflow\2.0-用例\项目管理样例\02-开发库\02-需求理解" --system_design_dir "F:\sandbox\workflow\2.0-用例\项目管理样例\02-开发库\03-系统设计"
```

---

### 阶段6：模块排期阶段

**功能描述**：
- 生成系统实现的排期计划
- 基于功能依赖和优先级确定开发顺序
- **哪个完成哪个先**

**核心技能**：
- [milestone-tracker](../1.0-软件开发流程角色agent模型/项目管理/skill/milestone-tracker.skill.md)
- [schedule-planner](../1.0-软件开发流程角色agent模型/项目管理/skill/schedule-planner.skill.md)

**输入参数**：
- `project_name`：项目名称（必填）
- `outline_design_dir`：概要设计文档目录（必填）
- `output_dir`：输出目录（默认：`F:\sandbox\workflow\2.0-用例\项目管理样例\02-开发库\05-详细设计`）
- `team_size`：团队人数（默认：5）
- `start_date`：开始日期（默认：当天）

**调用示例**：
```bash
/stage-06 --project_name "HIS系统" --outline_design_dir "F:\sandbox\workflow\2.0-用例\项目管理样例\02-开发库\04-概要设计" --team_size 5
```

### 阶段7：后端开发阶段

**功能描述**：
- 同步各阶段文档到目录
- 调用后端框架skill完成开发
- 调用检查工作流至项目没有error
- 生成前端对接文档

**核心技能**：
- [entity-designer-java](../1.0-软件开发流程角色agent模型/研发/skill/design/entity-designer-java.skill.md)
- [api-designer-java](../1.0-软件开发流程角色agent模型/研发/skill/design/api-designer-java.skill.md)
- [code-review-v2](../1.0-软件开发流程角色agent模型/研发/skill/process/code-review-v2.skill.md)

**输入参数**：
- `project_name`：项目名称（必填）
- `docs_dir`：各阶段文档目录（必填）
- `output_dir`：后端项目目录（必填）
- `backend_skill_path`：后端框架skill路径（默认：`F:\projects\yudao-ai-his-backend\CLAUDE.md`）
- `frontend_doc_dir`：前端对接文档目录（默认：`F:\projects\yudao-ai-his-backend\docs\his`）

**调用示例**：
```bash
/stage-07 --project_name "HIS系统" --docs_dir "F:\sandbox\workflow\2.0-用例\项目管理样例\02-开发库" --output_dir "F:\projects\yudao-ai-his-backend"
```

## 工作流执行流程

```
┌─────────────────────────────────────────────────────────────────┐
│                        需求分析阶段                               │
│  多Agent爬取资料 → 产品技能需求调研 → 产出PRD框架                   │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│                        需求开发阶段                               │
│  理解需求 → 提取功能点 → 产出BRD文档                               │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│                        需求理解阶段                               │
│  生成原型图 → 生成业务流程图 → 按模块分类组织文档                   │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│                        系统设计阶段                               │
│  需求分析 → 资料调研 → 指标估算 → 产出系统设计文档                  │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│                        概要设计阶段                               │
│  C4架构设计 → 数据库设计 → ADR决策记录                            │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│                        模块排期阶段                               │
│  依赖分析 → 优先级排序 → 工期估算 → 生成排期计划                    │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│                        后端开发阶段                               │
│  文档同步 → 调用框架skill → 检查错误 → 生成前端对接文档              │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│                        前端开发阶段                               │
│  文档同步 → API层开发 → 页面开发 → 检查错误                        │
└─────────────────────────────────────────────────────────────────┘
```

## 重要注意事项

1. **禁止Mock数据**：所有资料爬取必须使用WebSearch从真实网络获取
2. **绝对路径**：工作流启动时必须提供绝对路径参数
3. **按顺序执行**：各阶段有依赖关系，建议按顺序执行
4. **错误修复**：后端/前端开发阶段最多重试3次修复错误
5. **目录组织**：需求理解阶段必须按模块/子模块/功能点分类组织文档
