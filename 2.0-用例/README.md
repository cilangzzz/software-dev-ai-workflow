## 分类说明

### 一、Agent用例

各部门Agent的具体使用示例，展示如何通过Agent完成特定任务。

| 目录 | 说明 | 对应Agent |
|------|------|-----------|
| agent用例-产品 | 需求分析、PRD生成、用户故事 | requirement-analyzer, user-story-generator |
| agent用例-研发 | 架构设计、代码实现、代码审查 | architect, implement, code-review |
| agent用例-测试 | 测试用例生成、测试执行 | test-case-generator, test-executor |
| agent用例-设计 | 技术方案设计 | architect |
| agent用例-运维 | CI/CD配置、部署分析 | ci-cd-pipeline, deployment-analyzer |
| agent用例-安全 | 安全扫描、代码安全审查 | security-scan, security-code-review |
| agent用例-数据 | 数据血缘、数据质量检查 | data-lineage, data-quality-check |
| agent用例-项目管理 | 项目规划、进度跟踪 | project-manager |

### 二、开发流程样例

软件开发全生命周期流程规范，支持瀑布和敏捷两种模式。

| 目录 | 说明 |
|------|------|
| 00-流程管理框架 | 流程治理规范、角色职责 |
| 01-瀑布开发流程 | 传统瀑布模型各阶段流程 |
| 02-敏捷开发流程 | Scrum敏捷迭代流程 |
| 03-跨阶段流程 | 质量门控、变更管理、风险管理 |
| 04-流程仪表盘 | 阶段状态看板、效率指标 |
| 05-产出物总清单 | 各阶段产出物汇总 |

### 三、系统模型样例

各行业系统的完整模型模板，包含需求分析、模块设计、架构设计、测试用例等全生命周期产出物。

| 系统 | 说明 |
|------|------|
| ERP | 汽车制造业企业资源计划系统 |
| MES | 汽车整车装配制造执行系统 |
| VCP | 语音社区系统（类Discord/YY语音） |

### 四、项目管理样例

项目管理文档模板库。

| 目录 | 说明 |
|------|------|
| 01-管理库 | 项目管理制度、流程文档 |
| 02-开发库 | 开发规范、技术标准 |
| 03-源码库 | 代码模板、示例代码 |
| 04-版本发布库 | 发布流程、版本管理 |

## 使用指南

### 查找Agent用例

1. 进入 `agent用例/` 目录
2. 选择对应部门子目录
3. 参考示例中的输入输出格式

### 查找系统模型

1. 进入 `系统模型样例/` 目录
2. 选择目标系统（erp/mes/vcp）
3. 参考 `01-需求分析/`、`02-模块设计/`、`03-架构设计/` 等目录结构

### 查找开发流程

1. 进入 `开发流程样例/` 目录
2. 选择瀑布或敏捷流程
3. 查看各阶段的流程规范和产出物要求
