## 1. 模块概述

采购管理模块负责管理企业的采购业务流程，包括供应商选择、采购申请、采购订单、采购入库等核心功能。

### 1.1 功能范围

| 功能项 | 功能描述 | 优先级 |
|--------|----------|--------|
| 采购申请管理 | 采购需求的申请、审批流程 | P0 |
| 采购订单管理 | 采购订单的创建、审批、执行 | P0 |
| 供应商管理 | 供应商信息维护、评估 | P1 |
| 价格管理 | 采购价格维护、历史价格查询 | P1 |
| 采购入库 | 采购物料的入库确认 | P0 |

### 1.2 与其他模块的关系

- **销售管理模块**：根据销售订单生成采购需求
- **库存管理模块**：采购入库影响库存
- **财务管理模块**：采购付款、应付账款
- **供应商管理模块**：供应商信息共享

## 2. 数据模型设计

### 2.1 核心数据表

| 表名 | 说明 | 主要字段 |
|------|------|----------|
| mm_purchase_request | 采购申请 | id, request_no, requester, status |
| mm_purchase_order | 采购订单 | id, order_no, supplier_id, status |
| mm_purchase_item | 采购明细 | id, order_id, material_id, qty |

---

## 3. 接口设计（概要）

| 接口 | 方法 | 说明 |
|------|------|------|
| /mm/purchase-request/create | POST | 创建采购申请 |
| /mm/purchase-order/create | POST | 创建采购订单 |
| /mm/purchase-order/approve | POST | 审批采购订单 |

---

## 4. 状态流转

```
采购申请: 草稿 → 待审批 → 已审批 → 已转订单 → 完成
采购订单: 草稿 → 待审批 → 已审批 → 部分入库 → 完成入库 → 完成
```
