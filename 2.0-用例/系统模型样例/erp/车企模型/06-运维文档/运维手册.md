## 一、系统概述

### 1.1 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                      Nginx反向代理                           │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    Spring Boot应用                           │
│                  (多租户SaaS模式)                             │
└─────────────────────────────────────────────────────────────┘
                              │
        ┌─────────────────────┼─────────────────────┐
        ▼                     ▼                     ▼
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│   MySQL 8.x   │      │   Redis 6.x   │      │  RabbitMQ   │
│   主数据库    │      │   缓存/会话    │      │   消息队列   │
└──────────────┘      └──────────────┘      └──────────────┘
```

### 1.2 技术栈

| 组件 | 版本 | 用途 |
|------|------|------|
| Spring Boot | 2.7 | 应用框架 |
| MySQL | 8.x | 主数据库 |
| Redis | 6.x | 缓存、会话 |
| RabbitMQ | 3.x | 消息队列 |
| Flowable | 6.8.x | 工作流引擎 |
| Nginx | 1.20 | 反向代理 |

## 三、日常运维操作

### 3.1 服务启停

```bash
# 启动服务
systemctl start erp-app

# 停止服务
systemctl stop erp-app

# 重启服务
systemctl restart erp-app

# 查看状态
systemctl status erp-app
```

### 3.2 日志查看

```bash
# 应用日志
tail -f /var/log/erp/app.log

# 错误日志
tail -f /var/log/erp/error.log
```
