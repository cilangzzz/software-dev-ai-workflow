## 一、系统概述

汽车制造业ERP系统是一套面向汽车制造企业的企业资源计划系统，支持多租户、多工厂、多组织的数据隔离与共享。

### 1.1 系统功能

| 模块 | 功能说明 |
|------|----------|
| 销售管理 | 客户管理、销售订单、交付管理 |
| 采购管理 | 采购申请、采购订单、供应商管理 |
| 库存管理 | 入库、出库、库存盘点 |
| 生产计划 | MPS、MRP、生产订单 |
| 财务管理 | 应收应付、总账、报表 |

### 1.2 用户角色

| 角色 | 权限范围 |
|------|----------|
| 系统管理员 | 系统配置、用户管理、权限管理 |
| 销售经理 | 销售订单审批、客户管理 |
| 采购专员 | 采购申请、采购订单 |
| 财务会计 | 财务凭证、报表查询 |

## 二、登录与导航

### 2.1 系统登录

1. 打开浏览器，访问系统地址
2. 输入用户名和密码
3. 点击"登录"按钮
4. 进入系统主页

### 2.2 主导航菜单

左侧菜单栏包含：
- 首页
- 销售管理
- 采购管理
- 库存管理
- 生产计划
- 财务管理
- 系统管理
