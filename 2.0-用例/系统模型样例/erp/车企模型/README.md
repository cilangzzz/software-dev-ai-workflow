# 汽车制造业ERP系统模型

## 项目概述

本目录包含汽车制造业ERP系统的完整系统模型，通过AI Agent工作流框架自动生成。该模型覆盖需求分析、模块设计、架构设计、测试用例、用户文档和运维文档等全生命周期产出物。

## 技术架构

### 技术栈

| 层级 | 技术选型 |
|------|---------|
| 后端框架 | Spring Boot 2.7 + MyBatis Plus |
| 数据库 | MySQL 8.x |
| 前端框架 | Vue 3.x + Element Plus |
| 认证方式 | JWT Token + OAuth 2.0 |
| 接口规范 | RESTful API |
| 多租户 | tenant_id字段隔离 |

### 系统集成

| 集成系统 | 集成方式 | 集成内容 |
|---------|---------|---------|
| MES系统 | REST API | 生产工单、执行状态、质量数据 |
| WMS系统 | REST API | 库存同步、出入库指令 |
| SRM系统 | REST API | 采购协同、供应商数据 |
| 财务系统 | 数据库 | 凭证、科目、报表数据 |
| IoT平台 | MQTT/API | 设备数据、告警信息 |

## 如何使用Agent模型生成系统文档

### 一、Agent模型框架概述

Agent模型位于 `../../../1.0-软件开发流程角色agent模型/` 目录，包含以下角色Agent：

| 部门 | Agent角色 | 主要职责 | Skill数量 |
|------|----------|----------|-----------|
| 产品部 | requirement-analyzer, user-story-generator | 需求分析、用户故事生成 | 4 |
| 研发部 | architect, implement, code-review | 架构设计、代码实现 | 7 |
| 测试部 | test-case-generator, test-executor | 测试用例生成、测试执行 | 3 |
| 运维部 | ci-cd-pipeline, deployment-analyzer | CI/CD配置、部署分析 | 2 |
| 安全部 | security-scan, security-code-review | 安全扫描、代码安全审查 | 3 |
| 数据部 | data-lineage, data-quality-check | 数据血缘追踪、数据质量检查 | 2 |

### 二、生成流程

#### 步骤1：需求探讨（产品部Agent）

**触发方式**：
```
/requirement-analyzer
```

或自然语言：
```
"帮我分析这个需求：需要一个汽车制造业ERP系统"
```

**产出物示例**：
- `01-需求分析/PRD-ERP系统.md`
- `01-需求分析/00-ERP系统需求总览.md`

---

#### 步骤2：用户故事生成（产品部Agent）

**触发方式**：
```
/user-story-generator
```

**产出物示例**：
- `01-需求分析/UserStory-ERP系统.md`

---

#### 步骤3：架构设计（研发部Agent）

**触发方式**：
```
/architect
```

**产出物示例**：
- `03-架构设计/系统架构设计.md`
- `03-架构设计/数据库设计文档.md`
- `03-架构设计/API设计文档.md`

---

#### 步骤4：模块详细设计（研发部Agent）

**触发方式**：
```
/implement
```

**产出物示例**：
- `02-模块设计/01-销售管理模块.md`
- `02-模块设计/04-生产计划模块.md`
- ...（其他模块文档）

---

#### 步骤5：测试用例生成（测试部Agent）

**触发方式**：
```
/test-case-generator
```

**产出物示例**：
- `04-测试用例/功能测试用例.md`

---

#### 步骤6：用户文档生成（产品部Agent）

**触发方式**：
```
/user-manual-writer
```

**产出物示例**：
- `05-用户文档/用户手册.md`
- `05-用户文档/快速入门指南.md`

---

#### 步骤7：运维文档生成（运维部Agent）

**触发方式**：
```
/deployment-analyzer
```

**产出物示例**：
- `06-运维文档/运维手册.md`
- `06-运维文档/故障处理手册.md`
