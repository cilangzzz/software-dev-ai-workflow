## 二、销售管理模块测试用例

### TC-SD-001：创建销售订单

| 项目 | 内容 |
|------|------|
| 测试编号 | TC-SD-001 |
| 测试名称 | 创建销售订单 |
| 优先级 | P0 |
| 前置条件 | 已登录销售专员账号，客户数据已准备 |

**测试步骤：**
1. 进入销售管理模块
2. 点击"新建订单"
3. 选择客户
4. 添加订单行（物料、数量、价格）
5. 点击保存

**预期结果：**
- 订单成功创建
- 订单号自动生成
- 订单状态为"草稿"

---

### TC-SD-002：销售订单审批

| 项目 | 内容 |
|------|------|
| 测试编号 | TC-SD-002 |
| 测试名称 | 销售订单审批流程 |
| 优先级 | P0 |
| 前置条件 | 存在待审批的销售订单 |

**测试步骤：**
1. 登录销售经理账号
2. 进入审批列表
3. 选择待审批订单
4. 点击审批通过

**预期结果：**
- 订单状态变更为"已审批"
- 订单可进行后续出库操作
