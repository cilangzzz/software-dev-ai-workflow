# VCP语音社区系统 - 用户手册

**文档版本：** v1.0
**创建日期：** 2026-06-10

---

## 一、系统概述

VCP语音社区系统是一款支持用户创建社区、频道分类、多人语音房间的语音社交平台，类似Discord/YY语音。

### 1.1 核心功能

| 功能 | 说明 |
|------|------|
| 用户管理 | 注册登录、资料管理、好友系统 |
| 服务器管理 | 创建社区、邀请成员、角色权限 |
| 频道管理 | 文字频道、语音频道、分类管理 |
| 语音房间 | 多人语音、麦控、发言高亮 |
| 文字消息 | 消息收发、@提及、附件、表情反应 |

---

## 二、登录与注册

### 2.1 注册账号

1. 打开VCP应用
2. 点击"注册"
3. 选择注册方式：
   - 手机号注册：输入手机号，获取验证码
   - 邮箱注册：输入邮箱，获取验证码
4. 设置用户名和密码
5. 完成注册，自动登录

### 2.2 登录系统

1. 输入用户名/手机号/邮箱
2. 输入密码
3. 点击"登录"
4. 进入主界面

**注意**：连续5次密码错误，账号将被锁定15分钟。

---

## 三、创建和管理服务器

### 3.1 创建服务器

1. 点击左侧"+"按钮
2. 选择"创建服务器"
3. 输入服务器名称（2-100字符）
4. 选择服务器区域
5. 点击"创建"

### 3.2 邀请成员

1. 点击服务器名称
2. 选择"邀请成员"
3. 设置邀请参数（有效期、使用次数）
4. 复制邀请链接
5. 发送给好友

### 3.3 加入服务器

1. 点击左侧"+"按钮
2. 选择"加入服务器"
3. 输入邀请链接或邀请码
4. 点击"加入"

### 3.4 服务器设置

**权限要求**：服务器管理员

1. 点击服务器名称
2. 选择"服务器设置"
3. 可修改：服务器名称、图标、描述、区域、验证等级

### 3.5 角色管理

**权限要求**：服务器Owner

1. 点击服务器设置 → 角色
2. 创建角色
3. 设置角色名称、颜色、权限
4. 将角色分配给成员

---

## 四、频道使用

### 4.1 频道类型

| 类型 | 图标 | 说明 |
|------|------|------|
| 文字频道 | # | 发送文字消息、图片、文件 |
| 语音频道 | 🔊 | 进入语音房间进行语音聊天 |

### 4.2 创建频道

**权限要求**：MANAGE_CHANNELS权限

1. 点击分类旁边的"+"按钮
2. 选择频道类型
3. 输入频道名称
4. 设置频道主题（可选）
5. 点击"创建"

### 4.3 创建分类

1. 点击服务器名称
2. 选择"创建分类"
3. 输入分类名称
4. 点击"创建"

---

## 五、语音房间使用

### 5.1 加入语音房间

1. 点击语音频道名称
2. 等待连接建立
3. 进入语音房间

### 5.2 语音控制

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 静音 | Ctrl+Shift+M | 关闭/打开麦克风 |
| 闭麦 | Ctrl+Shift+D | 关闭/打开扬声器 |
| 断开 | Ctrl+Shift+L | 离开语音房间 |

### 5.3 调节音量

- 整体音量：点击左下角音量图标
- 单个成员：点击成员头像，拖动音量滑块

### 5.4 发言人高亮

当前正在说话的成员会有以下标识：
- 头像外圈高亮边框
- 用户名颜色变化
- 排在成员列表前列
- 实时音量指示条

## 六、文字消息

### 6.1 发送消息

1. 选择文字频道
2. 在输入框输入内容
3. 按Enter键或点击发送按钮

**消息限制**：
- 单条消息最多2000字符
- 图片最大10MB
- 文件最大50MB

### 6.2 @提及

| 提及方式 | 说明 |
|----------|------|
| @用户名 | 提及单个用户 |
| @角色名 | 提及该角色的所有用户 |
| @全体成员 | 提及频道内所有用户（需权限） |

### 6.3 发送图片/文件

1. 点击输入框旁的"+"按钮
2. 选择文件
3. 等待上传完成
4. 点击发送

### 6.4 编辑/删除消息

- 编辑：悬停消息 → 点击编辑图标 → 修改内容 → 保存
- 删除：悬停消息 → 点击删除图标 → 确认删除

**注意**：只能编辑发送后5分钟内的消息。

### 6.5 表情反应

1. 悬停在消息上
2. 点击表情图标
3. 选择Emoji表情

## 七、好友系统

### 7.1 添加好友

1. 点击"好友"标签
2. 点击"添加好友"
3. 输入用户名或用户ID
4. 点击"发送请求"

### 7.2 管理好友请求

1. 点击"好友"标签
2. 选择"好友请求"
3. 点击"接受"或"拒绝"

### 7.3 删除好友

1. 右键点击好友
2. 选择"删除好友"

---

## 八、通知管理

### 8.1 查看通知

1. 点击右上角通知图标
2. 查看所有未读通知

### 8.2 通知设置

**服务器级别**：
1. 右键点击服务器
2. 选择"通知设置"
3. 选择：所有消息 / 仅@提及 / 全部静音

**频道级别**：
1. 右键点击频道
2. 选择"通知设置"
3. 选择通知级别

---

## 九、系统设置

### 9.1 音频设置

1. 点击设置图标
2. 选择"语音与视频"
3. 设置：输入设备、输出设备、音量、回声消除、噪声抑制

### 9.2 主题设置

1. 点击设置图标
2. 选择"外观"
3. 选择：浅色 / 深色 / 跟随系统

### 9.3 快捷键设置

1. 点击设置图标
2. 选择"快捷键"
3. 自定义快捷键

## 十、常见问题

### Q: 无法连接语音房间？

**解决方案**：
1. 检查麦克风权限
2. 检查网络连接
3. 重启应用

### Q: 消息发送失败？

**解决方案**：
1. 检查网络连接
2. 检查是否有发送权限
3. 检查是否被慢速模式限制

### Q: 忘记密码？

**解决方案**：
1. 点击登录页面的"忘记密码"
2. 输入注册时的手机号或邮箱
3. 获取验证码重置密码
