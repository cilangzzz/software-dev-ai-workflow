## 5分钟快速上手

### 步骤1：注册账号

1. 打开VCP应用
2. 点击"注册"
3. 填写信息并验证邮箱

### 步骤2：创建服务器

1. 点击左侧"+"按钮
2. 选择"创建服务器"
3. 输入服务器名称
4. 选择服务器图标

### 步骤3：创建频道

1. 进入服务器设置
2. 点击"创建频道"
3. 选择频道类型（文字/语音）
4. 设置频道名称

### 步骤4：邀请好友

1. 点击服务器设置
2. 选择"邀请成员"
3. 复制邀请链接
4. 发送给好友

### 步骤5：开始语音

1. 点击语音频道
2. 自动加入语音房间
3. 点击麦克风按钮开始说话
