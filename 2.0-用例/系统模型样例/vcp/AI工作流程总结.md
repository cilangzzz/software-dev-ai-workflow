## 三、各阶段详细说明

### 阶段1：需求分析

**负责Agent**：产品部 - requirement-analyzer, user-story-generator

**输入**：
- 原始需求描述
- 用户访谈记录
- 竞品分析报告

**处理流程**：
1. 解析需求描述，识别核心需求点
2. 提取关键实体、角色、动作
3. 生成PRD框架文档
4. 输出待澄清问题清单
5. 根据PRD生成用户故事
6. 定义验收标准（Given-When-Then格式）

**产出物**：
- `01-需求分析/00-VCP系统需求总览.md`
- `01-需求分析/PRD-VCP系统.md`
- `01-需求分析/UserStory-VCP系统.md`
- `01-需求分析/验收标准-VCP系统.md`

**触发命令**：
```
/requirement-analyzer
/user-story-generator
```

---

### 阶段2：架构设计

**负责Agent**：研发部 - architect

**输入**：
- PRD文档
- 用户故事
- 验收标准

**处理流程**：
1. 分析需求文档，设计系统架构
2. 定义技术栈和组件划分
3. 设计数据库模型
4. 设计API接口规范
5. 设计部署架构

**产出物**：
- `03-架构设计/系统架构设计.md`
- `03-架构设计/数据库设计文档.md`
- `03-架构设计/API设计文档.md`

**触发命令**：
```
/architect
```

---

### 阶段3：模块设计

**负责Agent**：研发部 - implement

**输入**：
- 系统架构设计
- 数据库设计
- API设计

**处理流程**：
1. 解析功能规格和用户故事
2. 设计每个模块的数据模型
3. 定义业务规则和状态流转
4. 设计接口和权限配置
5. 编写模块详细设计文档

**产出物**：
- `02-模块设计/01-用户模块.md`
- `02-模块设计/02-服务器模块.md`
- `02-模块设计/03-频道模块.md`
- `02-模块设计/04-语音房间模块.md`
- `02-模块设计/05-文字消息模块.md`
- `02-模块设计/06-通知模块.md`
- `02-模块设计/07-管理审核模块.md`
- `02-模块设计/08-系统设置模块.md`

**触发命令**：
```
/implement
```

### 阶段4：测试用例生成

**负责Agent**：测试部 - test-case-generator

**输入**：

3. 覆盖正向和异常场景
4. 编写功能测试用例文档

**产出物**：
- `04-测试用例/功能测试用例.md`

**触发命令**：
```
/test-case-generator
```

### 阶段5：用户文档生成

**负责Agent**：产品部 - user-manual-writer

**输入**：

1. 根据功能设计生成用户手册
2. 编写操作步骤说明
3. 配置界面截图说明
4. 编写快速入门指南

**产出物**：
- `05-用户文档/用户手册.md`
- `05-用户文档/快速入门指南.md`

/user-manual-writer

## 四、Agent协作配置

Agent之间通过协作配置实现自动化流程：

```yaml
workflows:
  - name: requirement-to-design
    sequence:
      - agent: requirement-analyzer
        phase: 需求分析
        outputs:
          - PRD文档
          - 需求澄清清单
      - agent: architect
        phase: 架构设计
        inputs:
          - PRD文档
        outputs:
          - 系统架构设计
          - 数据库设计

  - name: design-to-implementation
    sequence:
      - agent: implement
        phase: 模块设计
        inputs:
          - 系统架构设计
          - 数据库设计
        outputs:
          - 模块设计文档
          - 数据模型
```

## 六、产出物模板

### 6.1 PRD模板

位于：`1.0-软件开发流程角色agent模型/产品/references/prd-template.md`

包含：
- 产品概述
- 功能范围
- 详细功能需求
- 非功能需求
- 技术选型
- 实施路线图

### 6.2 用户故事模板

位于：`1.0-软件开发流程角色agent模型/产品/references/srs-template.md`

格式：
```
**作为** [角色]
**我想要** [功能]
**以便于** [价值]

**验收标准：**
- Given [前置条件]
- When [触发动作]
- Then [预期结果]
```

### 6.3 架构设计模板

位于：`1.0-软件开发流程角色agent模型/研发/references/`

包含：
- 系统概述
- 架构图
- 服务划分
- 技术选型
- 数据流设计
- 部署架构
- 安全设计
- 扩展性设计

## 七、持续改进

### 7.1 文档更新流程

1. 需求变更时更新PRD和用户故事
2. 设计变更时更新架构设计文档
3. 代码变更时更新模块设计文档
4. 测试变更时更新测试用例

### 7.2 反馈收集

反馈记录在 `.workspace/feedback.md`，包括：
- 需求澄清
- 设计评审意见
- 代码审查建议
- 测试反馈
