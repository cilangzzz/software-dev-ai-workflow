## 一、系统概述

### 1.1 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                    Nginx/Gateway                            │
└─────────────────────────────────────────────────────────────┘
                              │
        ┌─────────────────────┼─────────────────────┐
        ▼                     ▼                     ▼
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│  应用服务     │      │   RTC服务     │      │   信令服务   │
│  (业务逻辑)   │      │  (语音/视频)  │      │  (WebSocket) │
└──────────────┘      └──────────────┘      └──────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  数据层（MySQL/PostgreSQL + Redis + 对象存储）                │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 技术栈

| 组件 | 用途 |
|------|------|
| 应用服务 | Spring Boot / Node.js |
| RTC引擎 | WebRTC / MediaSoup |
| 数据库 | MySQL / PostgreSQL |
| 缓存 | Redis |
| 消息队列 | RabbitMQ / Kafka |
| 对象存储 | MinIO / S3 |

|------|------|

| 内存 | 16GB+ |

## 三、日常运维操作

### 3.1 服务启停

```bash
# 启动应用服务
systemctl start vcp-app

# 启动RTC服务
systemctl start vcp-rtc

# 启动信令服务
systemctl start vcp-signal
```
