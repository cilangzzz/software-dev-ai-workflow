# VCP语音社区系统 - 验收标准

## 文档信息

| 属性 | 值 |
|------|-----|
| **产品名称** | VCP语音社区系统 |
| **版本** | 1.0 |

---

## 1. 用户模块验收标准

### 1.1 用户注册

- [ ] 用户可通过手机号+验证码注册账号
- [ ] 用户可通过邮箱+验证码注册账号
- [ ] 同一手机号/邮箱只能注册一个账号
- [ ] 用户名长度限制2-20字符
- [ ] 密码长度限制8-32字符，必须包含字母和数字
- [ ] 注册成功后自动登录

### 1.2 用户登录

- [ ] 用户可通过用户名/手机号/邮箱+密码登录
- [ ] 登录成功返回JWT Token
- [ ] 连续5次密码错误后账号锁定15分钟
- [ ] 锁定期间登录提示"账号已锁定"

### 1.3 用户资料管理

- [ ] 用户可编辑头像（支持jpg/png/gif，最大2MB）
- [ ] 用户可修改昵称（2-20字符）
- [ ] 用户可设置个性签名（最多100字符）
- [ ] 资料修改后立即生效

### 1.4 在线状态管理

- [ ] 用户可设置在线状态（在线/离开/DND/隐身）
- [ ] 登录后默认为"在线"状态
- [ ] 关闭客户端后自动设为"离线"
- [ ] 状态变更实时同步给好友和同服务器成员

### 1.5 好友系统

- [ ] 用户可通过用户名/ID搜索其他用户
- [ ] 可发送好友请求
- [ ] 可接受/拒绝好友请求
- [ ] 可删除好友
- [ ] 好友列表按在线状态分组展示
- [ ] 好友上线有提醒

---

## 2. 服务器模块验收标准

### 2.1 创建服务器

- [ ] 用户可创建服务器
- [ ] 服务器名称限制2-100字符
- [ ] 服务器图标支持上传（最大2MB）
- [ ] 创建者自动成为Owner
- [ ] 每用户最多创建10个服务器

### 2.2 服务器设置

- [ ] Owner可修改服务器名称、图标、描述
- [ ] 可设置服务器区域（影响语音节点选择）
- [ ] 可设置验证等级
- [ ] 可设置默认通知设置

### 2.3 邀请机制

- [ ] 可生成邀请链接
- [ ] 邀请链接可设置有效期（默认7天）
- [ ] 邀请链接可设置最大使用次数
- [ ] 过期或用尽的邀请链接无法使用
- [ ] 可手动更换邀请码

### 2.4 成员管理

- [ ] 用户可通过邀请链接加入服务器
- [ ] 成员可主动退出服务器
- [ ] 管理员可踢出成员
- [ ] 管理员可封禁成员
- [ ] 被封禁用户无法通过邀请加入

### 2.5 角色与权限

- [ ] 可创建自定义角色
- [ ] 角色可设置颜色
- [ ] 角色有层级关系
- [ ] 可为角色分配权限
- [ ] 可将角色分配给成员
- [ ] 高层级可管理低层级
- [ ] 不能踢出Owner

## 3. 频道模块验收标准

### 3.1 频道分类管理

- [ ] 可创建频道分类
- [ ] 分类名称限制1-100字符
- [ ] 分类支持拖拽排序
- [ ] 可折叠/展开分类
- [ ] 删除分类时频道移至"未分类"

### 3.2 文字频道

- [ ] 可创建文字频道
- [ ] 频道名称限制1-100字符，仅小写字母、数字、短横线
- [ ] 每服务器最多100个频道
- [ ] 支持置顶消息
- [ ] 支持慢速模式
- [ ] 支持仅管理员发言模式

### 3.3 语音频道

- [ ] 可创建语音频道
- [ ] 语音频道显示当前在线人数
- [ ] 可设置用户上限（默认20人）
- [ ] 可设置仅管理员可连接

### 3.4 频道权限配置

- [ ] 频道权限继承自服务器角色权限
- [ ] 可按频道单独覆盖权限
- [ ] 权限继承逻辑正确（角色默认→频道覆盖）
- [ ] 可按角色配置权限
- [ ] 可按单个成员配置权限

## 4. 语音房间模块验收标准

### 4.1 多人语音通话

- [ ] 用户连接语音频道后可进入语音房间
- [ ] 支持最多20人同时语音通话
- [ ] 音频延迟 < 200ms
- [ ] 支持Opus音频编码
- [ ] 支持48kHz采样率
- [ ] 支持自动增益控制（AGC）
- [ ] 支持回声消除（AEC）
- [ ] 支持噪声抑制（ANS）

### 4.2 麦克风/扬声器控制

- [ ] 用户可自我静音
- [ ] 用户可自我闭麦（不听）
- [ ] 用户可调节自己的收听音量
- [ ] 用户可调节单个成员的音量
- [ ] 管理员可静音其他成员
- [ ] 管理员可屏蔽其他成员音频

### 4.3 语音房间进入/退出

- [ ] 进入前检查CONNECT权限
- [ ] 进入前检查房间容量
- [ ] 请求麦克风权限
- [ ] WebRTC连接建立成功
- [ ] 加入后通知其他成员
- [ ] 主动断开连接可退出
- [ ] 关闭客户端自动断开
- [ ] 切换语音房间自动离开前一个

### 4.4 发言人高亮显示

- [ ] 正在说话的用户头像有高亮边框
- [ ] 发言人排在列表前列
- [ ] 实时音量指示条显示

### 4.5 语音质量调节

- [ ] 可调节音频采样率
- [ ] 可调节降噪等级
- [ ] 可开关自动增益控制
- [ ] 可开关回声消除

### 4.6 异常处理

- [ ] 麦克风权限被拒绝时提示用户
- [ ] 房间已满时提示用户
- [ ] 网络断开时30秒内自动重连
- [ ] WebRTC连接失败时尝试TURN中继

## 5. 文字消息模块验收标准

### 5.1 消息发送/接收

- [ ] 消息实时发送和接收（延迟 < 500ms）
- [ ] 消息内容最大2000字符
- [ ] 消息实时通过WebSocket推送
- [ ] 消息持久化存储

### 5.2 消息历史与搜索

- [ ] 历史消息分页加载（每次50条）
- [ ] 向上滚动加载更早消息
- [ ] 支持关键词搜索
- [ ] 支持按发送者筛选
- [ ] 支持按时间范围筛选

### 5.3 @提及

- [ ] @用户名可触发通知
- [ ] @角色名可触发该角色所有成员通知
- [ ] @全体成员需要MANAGE_MESSAGES权限
- [ ] 被@用户收到通知

### 5.4 引用回复

- [ ] 可引用当前频道内的消息
- [ ] 引用回复显示原消息摘要
- [ ] 点击引用可跳转到原消息

### 5.5 图片/文件发送

- [ ] 图片最大10MB（支持jpg/png/gif/webp）
- [ ] 文件最大50MB
- [ ] 图片在聊天中预览
- [ ] 文件显示名称、大小、类型

### 5.6 消息编辑/删除

- [ ] 只能编辑/删除自己发送的消息
- [ ] 编辑后显示"已编辑"标识
- [ ] 删除采用软删除
- [ ] 管理员可删除任意成员消息
- [ ] 消息发送后5分钟内可编辑

### 5.7 Emoji表情反应

- [ ] 可对消息添加Emoji反应
- [ ] 每条消息每个用户最多20个反应
- [ ] 相同反应显示数量
- [ ] 点击反应可切换（添加/取消）

### 5.8 慢速模式

- [ ] 慢速模式正确限制发送频率
- [ ] 无权限用户受限制
- [ ] 管理员不受限制

## 7. 管理审核模块验收标准

### 7.1 踢出成员

- [ ] 管理员可踢出普通成员
- [ ] 不能踢出Owner
- [ ] 不能踢出角色层级高于自己的成员
- [ ] 被踢出成员可重新通过邀请加入（未封禁时）

### 7.2 封禁成员

- [ ] 管理员可封禁成员
- [ ] 封禁后成员自动被踢出
- [ ] 被封禁用户无法通过任何邀请加入
- [ ] 可设置临时封禁（指定天数后自动解除）
- [ ] 可设置永久封禁
- [ ] 管理员可解除封禁

### 7.3 消息审核与删除

- [ ] 管理员可删除任意成员的消息
- [ ] 删除后显示"消息已被管理员删除"
- [ ] 支持批量删除消息
- [ ] 删除操作记录到日志

### 7.4 举报机制

- [ ] 成员可提交举报
- [ ] 举报需选择类型
- [ ] 管理员在审核面板查看举报
- [ ] 管理员可处理举报（删除/警告/封禁/忽略）
- [ ] 举报人收到处理结果通知

### 7.5 管理员操作日志

- [ ] 踢出成员记录日志
- [ ] 封禁/解封记录日志
- [ ] 删除消息记录日志
- [ ] 修改权限记录日志
- [ ] 处理举报记录日志

### 7.6 内容过滤

- [ ] 敏感词过滤自动拦截
- [ ] 支持自定义敏感词库
- [ ] 可设置过滤方式（删除/替换/警告）

## 9. 性能验收标准

| 指标 | 目标值 | 验收方法 |
|------|--------|----------|
| 语音延迟 | < 200ms | 端到端测量 |
| 消息推送延迟 | < 500ms | 从发送到接收的时间差 |
| 单语音房间人数 | 20人 | 实际测试 |

| API响应时间 | < 200ms | P95延迟 |
