# 入场与退场模式

## 入场策略

### 1. 滑入（直接入场）
**技术**：translate + opacity

| 个性 | 偏移 | 缓动 |
|------|------|------|
| Playful | 30-50px | ease-out-back |
| Premium | 15-25px | (0.4, 0, 0.2, 1) |
| Corporate | 20-30px | (0.2, 0, 0, 1) |

**方向语义**：
| 方向 | 含义 |
|------|------|
| 从下方 | 到达、出现 |
| 从右侧 | 前进 |
| 从左侧 | 返回 |

### 2. 缩放入场（涌现）
**技术**：scale + opacity

| 个性 | 起始缩放 |
|------|----------|
| Playful | 70-80% |
| Premium | 95-98% |
| Corporate | 90-95% |

**适合**：模态框、对话框、通知

### 3. 揭示入场
**技术**：clip-path + opacity
- 持续时间：300-500ms
- 方向：从上到下（戏剧性）、从左到右（阅读顺序）、从中心（焦点）

---

## 退场策略

**规则**：退场 = 入场的65-75%

### 1. 滑出
- 偏移20-40px + opacity 0
- ease-in
- 150-250ms

### 2. 淡出
- opacity（+ scale 98%）
- ease-in
- 150-250ms

### 3. 缩小消失
- scale 85-95% + opacity 0
- ease-in
- 150-250ms

---

## 常见配方

### 通知滑入
```
从右侧滑入 + opacity（250ms, ease-out）
过冲3-5%
图标50ms延迟后出现
```

### 模态框入场
```
1. 背景：opacity 0→50%（250ms）
2. 模态框：从下方50px + scale 95%→100%（350ms）
3. 内容：交错40ms淡入（100ms延迟）
```

### Toast消失
```
向边缘滑动 + opacity（180ms, ease-in）
剩余toast上移填补（200ms）
```

### 下拉菜单
```
1. 容器：scaleY 0→100%（200ms, ease-out）
2. 项目：交错30ms淡入（容器后50ms）
```
