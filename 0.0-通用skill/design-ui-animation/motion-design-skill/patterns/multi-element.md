# 多元素编排模式

## 交错策略

| 模式 | 延迟 | 总预算 | 用例 |
|------|------|--------|------|
| 微级联 | 20-40ms | <200ms | 列表、网格 |
| 标准 | 50-100ms | <400ms | 卡片、导航 |
| 戏剧性 | 100-200ms | <600ms | 主角区块 |

**总交错时间必须 <500ms**

---

## 交错实现

### 线性交错
```javascript
// GSAP
stagger: 50

// CSS
transition-delay: calc(var(--i) * 50ms);
```

### 中心扩展
```javascript
stagger: { each: 50, from: "center" }
```

### 边缘交错
```javascript
stagger: { each: 40, from: "start" }
```

## 主角与配角

### 视觉权重

| 角色 | 动画幅度 | 持续时间 |
|------|----------|----------|
| 主角 | 最大 | 最长 |
| 配角 | 70% | 80% |
| 背景 | 30% | 50% |

### 分层时机
```
0ms    ████████████ 主角
100ms      ████████ 配角
200ms          ████ 背景
```

---

## 编排示例

### 卡片网格
```
阶段1 (0-400ms): 网格入场
  - 交错50ms
  - 每张200ms
  - 左上到右下

阶段2 (100-300ms): 内容淡入
  - 卡片落地后
  - 交错30ms
```

### 导航栏
```
阶段1 (0-200ms): Logo
  - 从左侧滑入

阶段2 (100-400ms): 导航项
  - 交错40ms
  - 从上方淡入

阶段3 (200-300ms): 搜索/用户
  - 淡入
```

### 下拉菜单
```
阶段1 (0-200ms): 容器
  - scaleY 0→100%
  - ease-out

阶段2 (50-250ms): 菜单项
  - 交错30ms
  - 淡入上滑

阶段3: 阴影增长
```

### 模态框
```
阶段1 (0-250ms): 背景
  - opacity 0→50%

阶段2 (50-400ms): 模态框
  - 从下方50px + scale 95%→100%

阶段3 (150-500ms): 内容
  - 交错40ms
```

## 进场与退场协调

### 空间切换
```
阶段1 (0-300ms): 旧元素退出
  - 向左滑出 + 淡出

阶段2 (150-450ms): 新元素入场
  - 100ms重叠
  - 从右侧滑入
```
