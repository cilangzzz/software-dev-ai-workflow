```

```

## 悬停状态

| 元素 | 效果 | 持续时间 |
|------|------|----------|
| 按钮 | scale 1.02-1.05 | <100ms |
| 卡片 | scale 1.01 + 阴影提升 | <100ms |
| 链接 | 颜色 + 下划线 | <100ms |
| 图标 | scale 1.1 + rotation 2-5° | <100ms |

**悬停进入 <100ms；离开 150-200ms**

## 错误状态

### 错误抖动
```
水平振荡 ±10-15px
2-3次循环，ease-in-out
300-400ms
红色边框
无过冲
```

### 行内验证
```
错误文字下滑淡入（200ms）
边框→红色（150ms）
图标缩放入场（150ms, 50ms延迟）
```

### 表单错误
```
按钮恢复正常（200ms）
错误消息滑入（250ms）
字段红色高亮（150ms, 交错30ms）
滚动到第一个错误（300ms）
```
