# 故障排除

## 常见问题

### 动画机械/生硬
| 原因 | 修复 |
|------|------|
| 线性缓动 | 改用ease-out |
| 直线路径 | 添加弧线偏移 |
| 缺少次要运动 | 添加阴影/子元素反应 |

### 动画太慢
| 元素 | 正确时机 |
|------|----------|
| 工具提示 | 80-120ms |
| 按钮 | 120-180ms |
| 卡片 | 200-350ms |
| 模态框 | 300-400ms |

### 廉价/扁平
- 添加次要层（阴影、子元素）
- 结合位置或缩放（不只透明度）
- 使用方向缓动

### 太分散注意力
- 同时运动 ≤ 1/3元素
- 减小位移幅度
- 淡化非主角元素（40-60%）

### 没有个性
- 选择并应用动效原型
- 定义标志性缓动曲线
- 保持参数一致

### 错误状态用了弹跳
- 错误用抖动，无过冲
- 成功才用过冲弹跳

### 悬停响应慢
- 悬停进入 <100ms
- 悬停离开 150-200ms

### 滚动卡顿
- 只用transform/opacity
- 减少同时动画数量

---

## 快速诊断

| 问题 | 最可能原因 | 修复 |
|------|-----------|------|
| 机械感 | 线性缓动 | ease-out |
| 太慢 | 时间长 | 减至推荐值 |
| 廉价感 | 缺层次 | 添加次要层 |
| 分散 | 元素多 | 1/3规则 |
| 没个性 | 通用缓动 | 选原型 |
| 响应慢 | 悬停长 | <100ms |
