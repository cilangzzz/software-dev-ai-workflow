## 缓动曲线

### 行业标准

| 名称 | Cubic Bezier | 用途 |
|------|-------------|------|
| Material Design 3 | (0.2, 0, 0, 1) | 默认 |
| MD3 强调 | (0.05, 0.7, 0.1, 1) | 入场 |
| MD3 加速 | (0.3, 0, 1, 1) | 退场 |
| Apple HIG | (0.25, 0.1, 0.25, 1) | iOS |
| Bounce settle | (0.175, 0.885, 0.32, 1.275) | 弹跳 |
| Ease out back | (0.34, 1.56, 0.64, 1) | 过冲 |

### 按方向

| 方向 | 缓动 |
|------|------|
| 入场 | ease-out |
| 退场 | ease-in |
| 屏幕上 | ease-in-out |
| 循环 | sine ease-in-out |

---

## CSS预设

```css
/* 标准 */
--ease-out: cubic-bezier(0, 0, 0.2, 1);
--ease-in: cubic-bezier(0.4, 0, 1, 1);
--ease-in-out: cubic-bezier(0.4, 0, 0.2, 1);

/* Material Design 3 */
--md3-standard: cubic-bezier(0.2, 0, 0, 1);
--md3-emphasized: cubic-bezier(0.05, 0.7, 0.1, 1);

/* Apple HIG */
--apple-ease: cubic-bezier(0.25, 0.1, 0.25, 1);

/* 弹跳 */
--ease-out-back: cubic-bezier(0.34, 1.56, 0.64, 1);
```
