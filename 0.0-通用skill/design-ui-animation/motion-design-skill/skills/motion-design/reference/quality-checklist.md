# Quality Checklist (质量检查清单)

## 关键规则（绝不违反）

### 1. 缓动规则

- [ ] 空间运动绝不使用线性缓动
- [ ] 线性缓动仅用于：旋转器、进度条、计时器
- [ ] 入场使用ease-out系列
- [ ] 退场使用ease-in系列

### 2. 状态变化规则

- [ ] 重要状态变化不只使用透明度
- [ ] 状态变化结合位置或缩放
- [ ] 透明度变化配合visibility处理

### 3. 距离规则

- [ ] 运动距离不超过屏幕1/3无中间关键帧
- [ ] 长距离运动分阶段进行
- [ ] 超长距离使用淡入淡出过渡

### 4. 层次规则

- [ ] 有主要运动层
- [ ] 有次要运动层（阴影、子元素）
- [ ] 有环境运动层（背景、装饰）

---

## 高优先级规则（强烈遵循）

### 时机规则

- [ ] 持续时间与元素类型匹配
- [ ] 入场比退场长30-50%
- [ ] 交互反馈<100ms（悬停）<150ms（按下）

### 缓动规则

- [ ] 缓动曲线与品牌个性匹配
- [ ] 全项目缓动使用一致
- [ ] 情感表达与缓动匹配

### 迪士尼原则

- [ ] 有预备动作（重要动画）
- [ ] 有跟随通过效果
- [ ] 运动路径有弧线（非机械UI）

### 编排规则

- [ ] 有明确主角元素
- [ ] 入场方向一致
- [ ] 交错总时间<500ms

---

## 性能检查

### 属性使用

- [ ] 优先使用transform和opacity
- [ ] 避免动画width、height、margin、padding
- [ ] 避免动画top、left、right、bottom

### 硬件加速

- [ ] 使用`will-change`提示浏览器（谨慎使用）
- [ ] 使用`transform: translateZ(0)`触发GPU加速

### 数量控制

- [ ] 同时运动元素不超过总数的1/3
- [ ] 环境动画数量控制在合理范围

---

## 可访问性检查

### 减少动画偏好

- [ ] 提供`prefers-reduced-motion`回退
- [ ] 减少动画模式下停止或减少运动
- [ ] 重要信息不只依赖动画传达

### 实现示例

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

### 认知负担

- [ ] 动画不过于复杂
- [ ] 动画不过于快速或闪烁
- [ ] 用户可以停止连续动画

---

## 个性一致性检查

### 品牌个性

- [ ] 项目选择了单一动效原型
- [ ] 所有动画符合选定的原型
- [ ] 原型参数正确应用

| 原型 | 检查项 |
|------|--------|
| Playful | 有弹跳过冲、弧线路径、短时机 |
| Premium | 无过冲、长时机、平滑缓动 |
| Corporate | 最小过冲、中等时机、直线路径 |
| Energetic | 大过冲、最短时机、动态路径 |

### 参数一致性

- [ ] 定义了标志性缓动曲线
- [ ] 定义了持续时间调色板
- [ ] 定义了一致入场模式

---

## 视觉质量检查

### 运动流畅度

- [ ] 运动平滑无卡顿
- [ ] 缓动感觉自然
- [ ] 无突然停止

### 视觉层次

- [ ] 主角元素突出
- [ ] 次要元素支撑不抢眼
- [ ] 环境元素微妙不分散

### 空间感知

- [ ] 入场方向符合预期
- [ ] 运动路径符合空间逻辑
- [ ] 元素间空间关系清晰

---

## 最终发布检查清单

### 功能检查

- [ ] 动画正确触发
- [ ] 动画可被中断
- [ ] 动画结束后状态正确

### 性能检查

- [ ] 帧率稳定（目标60fps）
- [ ] 无明显延迟
- [ ] 移动端性能可接受

### 兼容性检查

- [ ] 主流浏览器表现一致
- [ ] 移动端体验良好
- [ ] 减少动画模式工作正常

### 用户体验检查

- [ ] 动画增强而非干扰
- [ ] 交互感觉响应迅速
- [ ] 状态变化清晰传达
