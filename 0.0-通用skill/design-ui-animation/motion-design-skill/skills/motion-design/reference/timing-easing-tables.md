# Timing & Easing Tables (时机与缓动表)

## 持续时间参考

### 按元素类型

| 元素类型 | 持续时间 | 理由 |
|----------|----------|------|
| 工具提示/微反馈 | 80-120ms | 必须感觉即时 |
| 按钮按压/切换 | 120-180ms | 响应式反馈 |
| 图标过渡 | 150-250ms | 清晰的状态变化 |
| 卡片入场/退场 | 200-350ms | 空间感知 |
| 下拉菜单 | 200-300ms | 快速展开 |
| 模态框/对话框 | 300-400ms | 焦点转移 |
| 侧边栏/抽屉 | 300-400ms | 空间重新配置 |
| 页面转场 | 400-600ms | 上下文切换 |
| 戏剧性揭示 | 600-1200ms | 戏剧性铺垫 |

### 按距离

| 距离 | 持续时间倍数 | 示例 |
|------|-------------|------|
| <100px | 1.0x（基准） | 工具提示出现 |
| 100-200px | 1.2x | 卡片入场 |
| 200-400px | 1.5x | 模态框入场 |
| >400px | 1.6x（最大） | 页面转场 |

### 按交互类型

| 交互 | 持续时间 | 缓动 |
|------|----------|------|
| 悬停进入 | <100ms | ease-out |
| 悬停离开 | 150-200ms | ease-in |
| 按下 | <50ms | ease-out |
| 释放 | 100-150ms | ease-out |

## 缓动曲线参考

### 行业标准缓动

| 名称 | Cubic Bezier | 用途 |
|------|-------------|------|
| **Material Design 3** | (0.2, 0, 0, 1) | 默认屏幕上 |
| **MD3 强调** | (0.05, 0.7, 0.1, 1) | 入场、注意 |
| **MD3 加速** | (0.3, 0, 1, 1) | 退场、消失 |
| **Apple HIG** | (0.25, 0.1, 0.25, 1) | iOS标准 |
| **Snappy UI** | (0.2, 0, 0, 1) | 快速、果断 |
| **Gentle float** | (0.4, 0, 0.2, 1) | 环境、背景 |
| **Bounce settle** | (0.175, 0.885, 0.32, 1.275) | 过冲、趣味 |
| **Ease out back** | (0.34, 1.56, 0.64, 1) | 弹回效果 |

### 按方向的缓动选择

| 方向 | 缓动系列 | 原因 |
|------|----------|------|
| 入场 | ease-out | 快开始，轻着陆 |
| 退场 | ease-in | 轻开始，快离开 |
| 屏幕上运动 | ease-in-out | 两端平滑 |
| 循环/环境 | sine ease-in-out | 无缝循环 |

### CSS预设

```css
/* 标准 */
--ease-linear: linear;
--ease-in: cubic-bezier(0.4, 0, 1, 1);
--ease-out: cubic-bezier(0, 0, 0.2, 1);
--ease-in-out: cubic-bezier(0.4, 0, 0.2, 1);

/* Material Design 3 */
--md3-standard: cubic-bezier(0.2, 0, 0, 1);
--md3-emphasized: cubic-bezier(0.05, 0.7, 0.1, 1);
--md3-decelerated: cubic-bezier(0, 0, 0, 1);
--md3-accelerated: cubic-bezier(0.3, 0, 1, 1);

/* 趣味效果 */
--ease-out-back: cubic-bezier(0.34, 1.56, 0.64, 1);
--ease-out-elastic: cubic-bezier(0.68, -0.55, 0.265, 1.55);
--ease-out-bounce: cubic-bezier(0.34, 1.56, 0.64, 1);

/* Apple HIG */
--apple-ease: cubic-bezier(0.25, 0.1, 0.25, 1);
```

## 按材质的缓动

| 材质 | 持续时间倍数 | 过冲 | 缓动特征 |
|------|-------------|------|----------|
| 刚性（金属、石头） | 1.2x | 0% | 高阻尼 |
| 弹性（橡胶、凝胶） | 0.8x | 15-25% | 弹跳回弹 |
| 流体（水、颜料） | 1.5x | 5% | 平滑流动 |
| 纸张（卡片、纸张） | 1.0x | 3-5% | 轻微弯曲 |
| 气体（烟雾、雾） | 2.0x | 0% | 缓慢扩散 |
| 玻璃（易碎） | 0.9x | 0% | 快速、精确 |

## 交错延迟参考

| 模式 | 延迟 | 总预算 | 用例 |
|------|------|--------|------|
| 微级联 | 20-40ms | <200ms | 列表项、网格单元格 |
| 标准 | 50-100ms | <400ms | 卡片、面板、导航 |
| 戏剧性 | 100-200ms | <600ms | 主角区块 |
| 波浪 | 30-60ms | <500ms | 数据可视化 |

**计算公式**：
```
总交错时间 = 单项动画时长 + (元素数 - 1) × 交错延迟
```
