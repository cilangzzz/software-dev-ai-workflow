# Troubleshooting (故障排除)

## 常见问题诊断

### 问题：动画看起来机械/生硬

**症状**：
- 运动感觉不自然
- 缺乏生命感
- 让人感觉是计算机生成的

**可能原因**：
1. 使用了线性缓动
2. 运动路径是直线
3. 缺少次要运动

**解决方案**：
| 问题 | 修复 |
|------|------|
| 线性缓动 | 改用ease-out（入场）或ease-in（退场） |
| 直线路径 | 在路径中点添加10-20px垂直偏移 |
| 缺少次要运动 | 添加阴影变化或子元素反应 |

---

### 问题：动画感觉太慢

**症状**：
- 用户等待动画完成
- 交互感觉迟钝
- 影响使用效率

**可能原因**：
1. 持续时间超出元素类型推荐值
2. 缓动曲线过于平缓
3. 距离与时机不匹配

**解决方案**：
| 元素类型 | 推荐时机 |
|----------|----------|
| 工具提示 | 80-120ms |
| 按钮 | 120-180ms |
| 卡片 | 200-350ms |
| 模态框 | 300-400ms |

**其他修复**：
- 使用更陡峭的缓动曲线
- 缩短距离或添加中间关键帧
- 考虑使用ease-out代替ease-in-out

---

### 问题：动画感觉廉价/扁平

**症状**：
- 缺乏精致感
- 感觉不够专业
- 视觉层次不清

**可能原因**：
1. 缺少次要和环境层
2. 只使用透明度变化
3. 缺少缓动变化

**解决方案**：
| 问题 | 修复 |
|------|------|
| 缺少层次 | 添加阴影运动、子元素反应 |
| 只有透明度 | 结合位置或缩放变化 |
| 缓动单调 | 根据方向选择不同缓动 |

**丰富度检查**：
- [ ] 主要层：主要运动
- [ ] 次要层：阴影、图标、边框变化
- [ ] 环境层：背景渐变、装饰微动

---

### 问题：动画太分散注意力

**症状**：
- 用户难以聚焦主要内容
- 视觉混乱
- 影响任务完成

**可能原因**：
1. 同时运动元素过多
2. 运动幅度过大
3. 颜色对比过强

**解决方案**：
| 问题 | 修复 |
|------|------|
| 元素过多 | 应用1/3规则：同时运动不超过1/3 |
| 幅度过大 | 减小位移距离或缩放比例 |
| 对比过强 | 降低颜色变化幅度 |

**编排优化**：
- 明确主角元素
- 淡化非主角元素（透明度40-60%）
- 增加交错延迟

---

### 问题：动画没有个性

**症状**：
- 感觉通用、无聊
- 缺乏品牌识别
- 没有情感传达

**可能原因**：
1. 使用默认缓动
2. 没有选择动效原型
3. 参数不一致

**解决方案**：
| 原型 | 缓动 | 过冲 | 时机 |
|------|------|------|------|
| Playful | ease-out-back | 10-20% | 150-300ms |
| Premium | (0.4,0,0.2,1) | 0% | 350-600ms |
| Corporate | (0.2,0,0,1) | 0-3% | 200-400ms |
| Energetic | ease-out-expo | 15-30% | 100-250ms |

**品牌定义**：
- 定义标志性缓动曲线
- 定义持续时间调色板
- 定义一致入场模式

---

### 问题：错误状态使用了弹跳

**症状**：
- 错误感觉不够严肃
- 用户困惑
- 情感传达错误

**原因**：错误状态使用了趣味性缓动

**解决方案**：
| 状态 | 推荐缓动 | 过冲 |
|------|----------|------|
| 错误 | ease-in-out | 0% |
| 成功 | ease-out-back | 5-15% |
| 警告 | ease-out | 0-5% |

**错误动画特点**：
- 使用抖动而非弹跳
- 无过冲效果
- 颜色使用红色调

---

### 问题：悬停延迟过长

**症状**：
- 用户重复点击
- 感觉无响应
- 交互体验差

**原因**：悬停动画时机过长

**解决方案**：
| 交互 | 推荐时机 |
|------|----------|
| 悬停进入 | <100ms |
| 悬停离开 | 150-200ms |
| 按下 | <50ms |
| 释放 | 100-150ms |

**注意**：悬停进入要快，离开可以稍慢（更精致）

---

### 问题：滚动动画卡顿

**症状**：
- 滚动时帧率下降
- 动画不流畅
- 影响整体体验

**可能原因**：
1. 使用了布局触发的属性
2. 同时触发过多动画
3. 缺少硬件加速

**解决方案**：
| 问题 | 修复 |
|------|------|
| 布局触发属性 | 只使用transform和opacity |
| 动画过多 | 减少同时触发的动画数量 |
| 缺少加速 | 添加`will-change: transform` |

---

### 问题：移动端动画性能差

**症状**：
- 移动设备动画卡顿
- 电池消耗增加
- 响应延迟

**解决方案**：
| 优化项 | 建议 |
|--------|------|
| 属性选择 | 只用transform和opacity |
| 动画数量 | 减少同时动画数量 |
| 复杂效果 | 移动端禁用或简化 |
| 环境动画 | 减少或禁用 |

---

## 快速诊断表

| 问题 | 最可能原因 | 快速修复 |
|------|-----------|----------|
| 机械感 | 线性缓动 | 改用ease-out |
| 太慢 | 持续时间长 | 减少至推荐值 |
| 廉价感 | 缺少层次 | 添加次要+环境层 |
| 分散注意力 | 元素过多 | 应用1/3规则 |
| 没个性 | 通用缓动 | 选择并应用原型 |
| 错误弹跳 | 缓动不当 | 使用抖动无过冲 |
| 响应慢 | 悬停太长 | 减至<100ms |
| 滚动卡 | 属性不当 | 只用transform/opacity |
| 移动差 | 复杂度过高 | 简化或禁用 |
