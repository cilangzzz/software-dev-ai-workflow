# Disney's 12 Principles — UI Adapted (迪士尼12原则UI适配)

## 1. Squash and Stretch (挤压与拉伸)

- 挤压：缩放至~[1.2, 0.8]；拉伸：~[0.85, 1.15]
- 冲击：2-4帧（30-65ms）；恢复：4-8帧（65-130ms）
- 保持体积：宽度+20% → 高度按比例减少
- 高端/奢华品牌跳过此原则

## 2. Anticipation (预备动作)

- 在主要动作前向相反方向做小幅运动
- 持续时间：100-200ms，幅度：主要动作的10-20%
- 按钮：扩展前先缩小3%；卡片：先移开5-10px
- 微反馈（<150ms）可跳过

## 3. Staging (分场/舞台布置)

- 非主角元素变暗至40-60%透明度；可选2-4px模糊
- 主角在支撑元素后100-200ms入场
- 每个时机节拍一个主要动作

## 4. Straight Ahead vs. Pose to Pose (直接动画 vs. 关键帧动画)

| 方法 | 感觉 | 最佳用途 |
|------|------|----------|
| 直接动画 | 流畅、自发 | 粒子、环境、生成艺术 |
| 关键帧动画 | 计划、控制 | UI转场、状态变化 |

## 5. Follow Through and Overlapping Action (跟随通过与重叠动作)

- 子元素延迟：父元素后50-150ms
- 尾随元素：停止时间偏移100-200ms
- 对尾随部分使用spring缓动（较低刚度=更多尾随）

## 6. Slow In and Slow Out (缓入缓出)

| 上下文 | 缓动 | 原因 |
|--------|------|------|
| 入场 | ease-out | 平滑到达 |
| 退场 | ease-in | 快速离开 |
| 屏幕上 | ease-in-out | 平滑旅程 |
| 环境循环 | sine ease-in-out | 无缝 |

**绝不**对空间运动使用线性。线性仅用于：旋转、进度条、计时器。

## 7. Arcs (弧线运动)

- 在路径中点添加10-20px垂直偏移
- 企业风格微妙（5px），趣味风格明显（20px+）
- 机械UI可以有意使用直线路径

## 8. Secondary Action (次要动作)

- 幅度：主要的30-50%；时机：主要后50-100ms
- 与主要动作不同的缓动
- 示例：卡片入场 → 阴影增长；按钮按压 → 波纹扩展

## 9. Timing (时机)

| 重量/情绪 | 持续时间 |
|-----------|----------|
| 重（模态框、页面） | 400-800ms |
| 轻（工具提示、切换） | 100-250ms |
| 悲伤/严肃 | 600ms+ |
| 快乐/轻松 | 200-400ms |
| 紧迫 | 100-200ms |

入场退场不对称：入场比退场长30-50%。

## 10. Exaggeration (夸张)

| 个性 | 夸张程度 |
|------|----------|
| Playful | 15-25% |
| Energetic | 20-30% |
| Corporate | 0-5% |
| Premium | 0% |

- 缩放过冲：目标外10-30%；旋转：±5-15°

## 11. Solid Drawing (实体绘制)

- 跨关键帧保持一致比例
- 结合缩放+旋转创造深度
- 阴影行为与隐含光源匹配

## 12. Appeal (吸引力)

- 平滑曲线优于尖锐角度；令人满意的时机
- 所有元素个性一致
- 吸引力杀手：生硬运动、不一致时机、突然停止、统一动画

## 组合原则

| 配方 | 使用的原则 |
|------|-----------|--------|
| 按钮按压 | 预备 + 挤压拉伸 + 跟随通过 + 次要 + 时机 |
| 卡片入场 | 预备 + 弧线 + 缓入缓出 + 跟随通过 + 分场 |
| 成功庆祝 | 夸张 + 次要 + 时机 + 挤压拉伸 + 吸引力 |
| 错误抖动 | 时机 + 缓入缓出 + 分场（无夸张） |
| 加载旋转器 | 时机 + 缓入缓出 + 吸引力 |
