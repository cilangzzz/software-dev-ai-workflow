# Core Philosophy (核心哲学)

## 三大支柱

每个动画必须在技术决策前满足三个支柱：

### 1. 情感意图 (Emotional Intent)

**问题**：观众应该感受到什么？

动画是情感的语言。在确定"如何动"之前，先确定"为什么动"。

| 情感 | 时机 | 缓动 | 路径 |
|------|------|------|------|
| 喜悦 | 快速、弹跳 | ease-out-back | 弧线向上 |
| 平静 | 缓慢、流动 | sine ease-in-out | 柔和曲线 |
| 紧迫 | 尖锐、快速 | ease-out | 直线 |
| 优雅 | 控制、缓慢 | (0.4,0,0.2,1) | 长弧线 |
| 悲伤 | 缓慢、下垂 | cubic ease-in-out | 下垂曲线 |

**驱动因素**：缓动曲线选择、时机节奏、运动幅度

### 2. 视觉叙事 (Visual Narrative)

**问题**：这个动画讲述的微故事是什么？

每个动画都是一个微型故事：铺垫 → 动作 → 结局

**故事结构**：
- **铺垫**：预备动作、场景设置
- **动作**：主要运动发生
- **结局**：稳定、次要运动收尾

**驱动因素**：元素入场顺序、持续时间分配、分阶段策略

### 3. 动效工艺 (Motion Craft)

**问题**：如何让动画可信？

动画必须遵循用户对物理世界的直觉。

**物理考虑**：
- 重量感：重元素移动慢，轻元素移动快
- 惯性：元素不会瞬间停止
- 环境影响：重力、阻力、弹性

**驱动因素**：缓动曲线形状、过冲程度、稳定行为

## 三个动效层

**扁平动画的问题**：只有一个层次的运动感觉廉价、无生命。

### 主要层 (Primary Layer)

观众跟随的主要动作。

- 最突出的运动
- 最长的持续时间
- 最高的视觉权重

### 次要层 (Secondary Layer)

支撑丰富度的运动。

- 阴影位移
- 图标微动
- 边框变化
- 子元素反应

**时机**：主要层后50-100ms

### 环境层 (Ambient Layer)

背景生命力。

- 渐变脉动
- 装饰元素微动
- 背景纹理变化
- 环境粒子

**特征**：连续、微妙、循环

## 决策框架

```
1. 情感目标？
   ↓
2. 品牌个性（原型选择）
   ↓
3. 元素类型（时机基准）
   ↓
4. 主要属性选择
   ↓
5. 缓动曲线确定
   ↓
6. 次要 + 环境层规划
   ↓
7. 编排策略（多元素时）
   ↓
8. 质量检查
```

## 关键心智模型

### 距离感知

用户感知的动画时长受距离影响：
- 短距离（<100px）：感觉应该快
- 中距离（100-300px）：标准时机
- 长距离（>300px）：需要更多时间或中间关键帧

### 重量感知

元素的视觉重量影响时机预期：
- 模态框、覆盖层：重、慢
- 卡片、面板：中等
- 工具提示、徽章：轻、快

### 意图感知

运动方式传达意图：
- 直线：有目的、高效
- 弧线：自然、友好
- 螺旋：异想天开、装饰性

## 常见错误

| 错误 | 问题 | 修复 |
|------|------|------|
| 线性空间运动 | 机械、无生命 | 总是使用缓动曲线 |
| 仅透明度变化 | 扁平、廉价 | 结合位置或缩放 |
| 缺少次要层 | 无生命感 | 添加阴影、子元素运动 |
| 过长距离无停顿 | 无聊、冗长 | 添加中间关键帧 |
| 所有元素同时运动 | 混乱、分散 | 应用交错和1/3规则 |
