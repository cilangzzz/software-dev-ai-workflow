# Motion Personality (动效人格)

## 四大原型

每个项目选择一个原型。保持一致应用以建立品牌动效识别。

### Playful（趣味）

**关键词**：有趣、异想天开、弹跳、可爱

| 参数 | 值 |
|------|-----|
| 持续时间 | 150-300ms |
| 缓动 | ease-out-back |
| 过冲 | 10-20% |
| 路径 | 明显弧线（15-20px） |

**适合**：
- 儿童/青少年产品
- 游戏/娱乐应用
- 创意工具
- 社交媒体

**示例**：
- 按钮按压：弹跳反馈
- 卡片入场：从下方弹出
- 成功状态：活泼的粒子效果

### Premium（高端）

**关键词**：优雅、极简、奢华、精致

| 参数 | 值 |
|------|-----|
| 持续时间 | 350-600ms |
| 缓动 | cubic-bezier(0.4,0,0.2,1) |
| 过冲 | 0% |
| 路径 | 微妙曲线（5-10px） |

**适合**：
- 奢侈品牌
- 高端产品
- 金融/法律服务
- 婚礼/活动

**示例**：
- 按钮按压：优雅的轻微缩放
- 卡片入场：平滑淡入上滑
- 页面转场：缓慢、流畅的过渡

### Corporate（企业）

**关键词**：干净、专业、商务、仪表板

| 参数 | 值 |
|------|-----|
| 持续时间 | 200-400ms |
| 缓动 | cubic-bezier(0.2,0,0,1) |
| 过冲 | 0-3% |
| 路径 | 直线或极微妙曲线 |

**适合**：
- B2B产品
- 企业软件
- 仪表板/管理后台
- 专业服务

**示例**：
- 按钮按压：简洁的缩放
- 卡片入场：直接滑入
- 状态变化：清晰、直接

### Energetic（活力）

**关键词**：动态、充满活力、大胆、刺激

| 参数 | 值 |
|------|-----|
| 持续时间 | 100-250ms |
| 缓动 | ease-out-expo |
| 过冲 | 15-30% |
| 路径 | 大幅度弧线（20px+） |

**适合**：
- 运动/健身应用
- 音乐/娱乐平台
- 年轻人社交
- 活动推广

**示例**：
- 按钮按压：快速弹跳
- 卡片入场：快速滑入
- 成功状态：爆发式庆祝

## 品牌动效识别

建立一致的品牌动效需要定义三个常量：

### 1. 标志性缓动

一个曲线用于80%的动画。

**选择方法**：
1. 确定品牌个性原型
2. 选择对应的缓动曲线
3. 在项目中一致应用

**存储方式**：
```css
/* CSS变量 */
--ease-brand: cubic-bezier(0.4, 0, 0.2, 1);

/* Tailwind配置 */
transitionTimingFunction: {
  'brand': 'cubic-bezier(0.4, 0, 0.2, 1)',
}
```

### 2. 持续时间调色板

定义3个标准持续时间。

| 档位 | 持续时间 | 用途 |
|------|----------|------|
| 快速 | 100-150ms | 微交互、悬停 |
| 标准 | 200-300ms | 大多数UI动画 |
| 慢速 | 400-600ms | 页面转场、戏剧效果 |

```css
/* CSS变量 */
--duration-fast: 120ms;
--duration-standard: 250ms;
--duration-slow: 450ms;
```

### 3. 入场模式

一个一致的入场风格。

**选择入场类型**：
| 类型 | 描述 | 适合原型 |
|------|------|----------|
| 滑入 | 从一侧滑入 + 淡入 | Corporate |
| 弹入 | 缩放 + 弹跳 | Playful, Energetic |
| 淡入上滑 | 位置 + 透明度 | Premium |
| 展开显示 | clip-path展开 | 现代感 |

## 混合策略

有时需要在同一项目中混合原型。

### 主次策略

一个主原型（80%），一个次原型（20%）。

**示例**：
- 企业产品 + 趣味插图
- 主：Corporate（UI动画）
- 次：Playful（插图、吉祥物）

### 场景策略

不同场景使用不同原型。

| 场景 | 推荐 |
|------|------|
| 主UI | Corporate |
| 成功庆祝 | Playful/Energetic |
| 错误状态 | Corporate（严肃） |
| 营销页面 | Energetic |
| 设置页面 | Corporate |
