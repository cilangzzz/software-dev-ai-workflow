# Emotion Mapping (情感映射)

## 情感到动效的翻译

动画是情感的语言。以下是如何将情感转化为具体的动效参数。

### 基础映射表

| 情感 | 特征 | 路径 | 缓动 | 持续时间 |
|------|------|------|------|----------|
| 喜悦 | 弹跳、弧线 | 曲线、向上 | ease-out-back | 200-400ms |
| 平静 | 平滑、流动 | 轻柔曲线 | sine ease-in-out | 500-1000ms |
| 紧迫 | 尖锐、快速 | 直线 | ease-out | 100-200ms |
| 悲伤 | 缓慢、下垂 | 下垂曲线 | cubic ease-in-out | 600-1200ms |
| 惊讶 | 突然、扩展 | 径向向外 | ease-out-expo | 150-300ms |
| 优雅 | 缓慢、控制 | 长弧线 | (0.4,0,0.2,1) | 400-700ms |
| 趣味 | 弹跳、不规则 | 弧线、波浪 | ease-out-back | 200-350ms |
| 愤怒 | 尖锐、剧烈 | 直线、锯齿 | ease-in-out | 100-200ms |
| 期待 | 缓慢、渐进 | 短距离 | ease-in | 300-500ms |
| 满足 | 平滑、稳定 | 短弧线 | ease-out | 200-300ms |

## 路径即语言

运动路径传达意义，与速度和时机无关。

### 直线路径

- **含义**：效率、目的、机械
- **用例**：工具、仪表板、企业UI
- **避免**：趣味应用、情感内容

### 弧线路径

- **含义**：自然、友好、有机
- **用例**：社交应用、消费产品、儿童UI
- **强度**：小弧线(5px)=微妙，大弧线(20px+)=明显

### 螺旋路径

- **含义**：异想天开、装饰性、创意
- **用例**：艺术应用、游戏、特殊效果
- **谨慎使用**：过多会分散注意力

### 对角线路径

- **含义**：进步、增长、动态
- **用例**：进度指示、成功状态、数据可视化
- **方向**：左下到右上=增长；右上到左下=减少

### 垂直路径

- **含义**：重力、重量、层级
- **用例**：下拉菜单、通知、覆盖层
- **方向**：向下=到达/重量；向上=上升/轻盈

### 水平路径

- **含义**：进度、导航、序列
- **用例**：轮播、步骤指示、滑块
- **方向**：左到右=前进；右到左=返回

## 情感组合

真实场景中常需要组合多种情感。

### 成功 = 喜悦 + 满足

```
阶段1 (喜悦): 弹跳入场
  - 缩放弹出（ease-out-back, 200ms）
  - 向上弧线运动

阶段2 (满足): 稳定
  - 平滑稳定（ease-out, 150ms）
  - 绿色填充
```

### 警告 = 期待 + 紧迫

```
阶段1 (期待): 注意
  - 黄色边框脉动（sine, 500ms）
  - 图标轻微旋转

阶段2 (紧迫): 行动召唤
  - 快速脉冲（ease-out, 100ms）
  - 边框强度增加
```

### 错误 = 愤怒 + 悲伤（轻微）

```
阶段1 (愤怒): 抖动
  - 水平振荡（ease-in-out, 300ms）
  - 红色边框

阶段2 (悲伤): 稳定
  - 缓慢稳定（cubic ease-in-out, 200ms）
  - 持续红色
```

## 颜色心理学增强

动效与颜色结合增强情感传达。

| 情感 | 颜色 | 动效配合 |
|------|------|----------|
| 成功/喜悦 | 绿色 | 弹跳、向上 |
| 警告/注意 | 黄色/橙色 | 脉动、震荡 |
| 错误/危险 | 红色 | 抖动、快速 |
| 信息/中性 | 蓝色 | 平滑、稳定 |
| 平静/信任 | 蓝绿色 | 缓慢、流动 |
| 激情/能量 | 红色/紫色 | 快速、动态 |

## 案例研究

### 支付成功

**情感**：喜悦 + 满足 + 信任

```
阶段1 (0-200ms): 变形
  - 旋转器 → 对勾变形（crossfade, 200ms）
  - 缓动：ease-out

阶段2 (100-300ms): 弹出
  - 对勾绘制（stroke, 150ms）
  - 容器缩放弹出（ease-out-back, 200ms）
  - 颜色：绿色填充（200ms）

阶段3 (200-400ms): 确认
  - 文字淡入（200ms, 100ms延迟）
  - 可选：粒子庆祝效果（300-500ms）

阶段4 (环境): 背景
  - 微妙的绿色光晕脉动（sine, 2s循环）
```

### 错误抖动

**情感**：愤怒（轻微）+ 警告

```
阶段1 (0-300ms): 抖动
  - 水平振荡 ±10-15px
  - 2-3次循环，幅度递减
  - 缓动：ease-in-out（尖锐停止）

阶段2 (持续): 强调
  - 红色边框（150ms）
  - 图标脉动（sine, 可选）

注意：错误不需要喜悦，避免弹跳
```

### 加载状态

**情感**：期待 + 平静

```
旋转器：连续旋转（linear, 1-1.5s/圈）
脉冲：微妙的呼吸效果（sine, 2-3s循环）
颜色：品牌色或中性蓝色

注意：避免过于快速或复杂，保持平静感
```
