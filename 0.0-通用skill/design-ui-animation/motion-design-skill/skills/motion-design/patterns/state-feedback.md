# State & Feedback Patterns (状态与反馈模式)

## 按钮按压

### Playful（趣味）

```
按压：缩放至0.95（60ms, ease-out）
释放：过冲至1.05（80ms）
稳定：1.0（120ms, spring）
次要：阴影收缩/增长；颜色变暗/变亮
总计：约260ms
```

### Premium（高端）

```
按压：缩放至0.98（80ms）
释放：1.0（150ms，无过冲）
透明度按压时变暗至90%
总计：约230ms
```

### Corporate（企业）

```
按压：缩放至0.97（60ms）
释放：1.0（100ms）
过冲0-2%
背景变暗10%
总计：约160ms
```

## 悬停状态

| 元素 | 效果 | 持续时间 |
|------|------|----------|
| 按钮 | 缩放1.02-1.05 | <100ms |
| 卡片 | 缩放1.01-1.02 + 阴影提升 | <100ms |
| 链接 | 颜色变化 + 下划线 | <100ms |
| 图标 | 缩放1.1 + 旋转2-5° | <100ms |
| 图片 | 缩放1.03（overflow hidden） | 150ms |

**注意**：悬停入场 <100ms；悬停退场150-200ms（较慢=精致）

## 切换/开关

```
拇指滑动（120-180ms, ease-in-out）
轨道颜色同时过渡
运动方向轻微挤压
Playful：目的地弹跳
Premium：平滑无过冲
```

## 成功状态

### 对勾成功

```
1. 容器：缩放0.9→1.0（200ms, ease-out-back, 5-10%过冲）
2. 对勾：笔画绘制（150ms, ease-out, 100ms延迟）
3. 颜色：变绿（200ms）
4. 环境：光晕/粒子（300ms）
总计：400-500ms
```

### 确认徽章

```
1. 徽章从0缩放（200ms, ease-out-back）
2. 文字淡入（150ms, 50ms延迟）
3. 背景脉冲（300ms, sine）
```

### 支付成功

```
1. 旋转器 → 对勾交叉淡入淡出（200ms）
2. 对勾绘制（200ms）
3. 容器 → 成功颜色（200ms）
4. 文字淡入（200ms, 100ms延迟）
5. 可选：彩带庆祝（300-500ms）
```

## 错误状态

### 错误抖动

```
水平振荡 ±10-15px，2-3次循环递减幅度
ease-in-out，总计300-400ms
红色调
无过冲
稳定在原点
```

### 行内验证

```
1. 错误文字下滑 + 淡入（200ms）
2. 边框 → 红色（150ms）
3. 图标缩放入场（150ms, 50ms延迟）
4. 可选：单次抖动（200ms）
```

### 表单提交错误

```
1. 按钮恢复正常（200ms）
2. 错误消息滑入（250ms）
3. 受影响字段红色高亮（150ms, 交错30ms）
4. 平滑滚动到第一个错误（300ms, ease-in-out）
```

---

## 加载状态

### 旋转器

```
连续360°，linear，1000-1500ms/圈
可选呼吸脉冲（2-3s）
```

### 骨架屏

```
渐变从左到右扫过，1500-2000ms
基础透明度10-20%，峰值30-40%
```

### 进度条

```
宽度/transform，ease-in-out
可选颜色里程碑 + 光泽
```

### 不确定进度

```
振荡位置/宽度，1500-2500ms，ease-in-out
连续，不急躁
```

---

## 警告状态

```
1. 黄色/琥珀色边框（150ms）
2. 警告图标缩放入场（150ms, 微妙过冲）
3. 可选图标脉冲（2-3s, sine）
4. 文字淡入（200ms, 50ms延迟）
```

---

## 禁用/启用

```
禁用：透明度至50-60%（200ms）；可选缩放至98%
启用：透明度至100%（200ms）；可选缩放脉冲98%→100%
```

---

## 焦点状态

```
焦点环：缩放95%→100% + 透明度（150ms）
卡片焦点：缩放1.01，阴影增加（150ms）
标签导航焦点：<100ms；必须与减少动画兼容
```

---

## 状态转换时机参考

| 状态变化 | 推荐时机 | 缓动 |
|----------|----------|------|
| 默认 → 悬停 | <100ms | ease-out |
| 悬停 → 按下 | <50ms | ease-out |
| 按下 → 释放 | 100-150ms | ease-out |
| 加载 → 成功 | 300-400ms | ease-out |
| 加载 → 错误 | 300-400ms | ease-in-out |
| 成功 → 默认 | 200-300ms | ease-in |
| 错误 → 默认 | 200-300ms | ease-in |
