# Multi-Element Choreography (多元素编排)

## 交错策略详解

### 线性交错

每个元素等距延迟。

```javascript
// GSAP示例
gsap.to(".item", {
  y: 0,
  opacity: 1,
  stagger: 50 // 每项延迟50ms
});
```

**适合**：简单列表、网格

### 中心扩展交错

从中心元素开始，向两端扩散。

```javascript
// GSAP示例
gsap.to(".item", {
  scale: 1,
  stagger: {
    each: 50,
    from: "center"
  }
});
```

**适合**：轮播焦点、圆形布局

### 随机交错

元素以随机顺序入场。

```javascript
// GSAP示例
gsap.to(".item", {
  opacity: 1,
  stagger: {
    each: 50,
    from: "random"
  }
});
```

**适合**：趣味场景、创意展示

### 边缘交错

从边缘向中间，或从一端到另一端。

```javascript
// GSAP示例
gsap.to(".item", {
  x: 0,
  stagger: {
    each: 40,
    from: "start" // 或 "end", "edges"
  }
});
```

**适合**：导航、列表、时间线

## 交错预算管理

### 时间预算

**规则**：总交错时间 < 500ms

**计算**：
```
总时间 = 单项动画时长 + (元素数 - 1) × 交错延迟
```

**示例**：
- 5个元素，200ms动画，50ms交错
- 总时间 = 200 + 4 × 50 = 400ms ✅

### 视觉预算

**规则**：同时运动的元素不超过1/3

**解决方案**：
- 增加交错延迟
- 分组运动
- 入场后再退出其他

## 常见编排模式

### 卡片网格入场

```
阶段1 (0-400ms): 网格入场
  - 交错50ms
  - 每张卡片200ms
  - 从左上到右下

阶段2 (100-300ms): 内容淡入
  - 卡片落地后开始
  - 交错30ms
```

### 导航栏入场

```
阶段1 (0-200ms): Logo入场
  - 从左侧滑入

阶段2 (100-400ms): 导航项
  - 交错40ms
  - 从上方淡入

阶段3 (200-300ms): 搜索/用户
  - 淡入
```

### 仪表板入场

```
阶段1 (0-350ms): 主角图表
  - 从下方滑入
  - 最大视觉权重

阶段2 (100-450ms): 统计卡片
  - 交错50ms
  - 较低视觉权重

阶段3 (300-500ms): 侧边栏
  - 淡入
  - 最低视觉权重
```

### 表单入场

```
阶段1 (0-250ms): 标题
  - 从下方滑入

阶段2 (100-500ms): 表单字段
  - 交错50ms
  - 淡入上滑

阶段3 (300-400ms): 提交按钮
  - 缩放入场
```

## 主角与配角分离

### 视觉权重分配

| 角色 | 动画幅度 | 持续时间 | 缓动 |
|------|----------|----------|------|
| 主角 | 最大 | 最长 | 最强 |
| 配角 | 70% | 80% | 标准 |
| 背景 | 30% | 50% | 最轻 |

### 分层时机

```
时间轴:
0ms    ████████████████████████ 主角
100ms          ████████████████ 配角1
150ms                  ████████ 配角2
200ms                      ████ 背景
```

## 进场与退场协调

### 空间切换

当一个元素退出，另一个入场：

```
阶段1 (0-300ms): 旧元素退出
  - 向左滑出
  - 透明度渐变

阶段2 (150-450ms): 新元素入场
  - 100ms重叠
  - 从右侧滑入
```

### 变形过渡

元素变形为另一个：

```
阶段1 (0-200ms): 收缩
  - 缩小 + 透明度

阶段2 (100-300ms): 扩展
  - 新元素缩放入场
  - 透明度
```

## 复杂场景示例

### 下拉菜单打开

```
阶段1 (0-200ms): 容器
  - Y轴缩放0→100%
  - ease-out

阶段2 (50-250ms): 菜单项
  - 容器后50ms开始
  - 交错30ms
  - 淡入上滑

阶段3 (环境): 背景
  - 微妙的阴影增长
```

### 模态框入场

```
阶段1 (0-250ms): 背景
  - 透明度0→50%
  - ease-out

阶段2 (50-400ms): 模态框
  - 从下方50px + 缩放95%→100%
  - ease-out

阶段3 (150-500ms): 内容
  - 模态框后100ms开始
  - 交错40ms
```

### Toast队列

```
新Toast入场:
1. 从右侧滑入（250ms）
2. 现有Toast上移（200ms, 50ms延迟）

Toast退场:
1. 向边缘滑出（180ms）
2. 下方Toast上移填补空间（200ms）
```
