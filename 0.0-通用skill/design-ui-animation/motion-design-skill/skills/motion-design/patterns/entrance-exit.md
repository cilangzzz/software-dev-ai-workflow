# Entrance & Exit Patterns (入场与退场模式)

## 入场策略

### 1. 直接入场（滑入）

**技术**：位置 + 透明度；偏移20-40px + 透明度0 → 最终位置 + 透明度1

| 个性 | 偏移 | 缓动 | 过冲 |
|------|------|------|------|
| Playful | 30-50px | ease-out-back | 10-15% |
| Premium | 15-25px | (0.4, 0, 0.2, 1) | 0% |
| Corporate | 20-30px | (0.2, 0, 0, 1) | 0-3% |
| Energetic | 40-80px | ease-out-expo | 15-25% |

**方向语义**：
| 方向 | 含义 |
|------|------|
| 从下方 | 到达、出现 |
| 从右侧 | 前进、下一个 |
| 从左侧 | 返回、上一个 |
| 从上方 | 下拉、权威 |

### 2. 涌现入场（缩放入场）

**技术**：缩放 + 透明度；开始85-95% + 透明度0 → 100% + 透明度1

| 个性 | 起始缩放 | 缓动 | 过冲 |
|------|----------|------|------|
| Playful | 70-80% | ease-out-back | 10-20% |
| Premium | 95-98% | (0.4, 0, 0.2, 1) | 0% |
| Corporate | 90-95% | (0.2, 0, 0, 1) | 0-3% |
| Energetic | 50-70% | ease-out-expo | 15-30% |

**适合**：模态框、对话框、通知、弹出框、工具提示

### 3. 揭示入场（裁剪/遮罩）

**技术**：clip-path 或 mask + 透明度；300-500ms，ease-out

**方向**：
| 方向 | 效果 |
|------|------|
| 从上到下 | 戏剧性 |
| 从左到右 | 阅读顺序 |
| 从中心向外 | 焦点 |
| 从边缘向内 | 包含感 |

### 4. 组装入场（多部件）

**技术**：部件从不同位置到达；交错50-100ms；总计300-600ms

**适合**：图标组装、Logo构建、数据可视化构建

---

## 退场策略

**规则**：退场 = 入场时长的65-75%

### 1. 直接退场（滑出）

**技术**：偏移20-40px + 透明度0；ease-in；150-250ms

### 2. 溶解退场（淡出）

**技术**：透明度（+ 可选缩放至98%）；ease-in；150-250ms

**适合**：温和离开、背景化、交叉淡入淡出

### 3. 收缩退场（缩小消失）

**技术**：缩放85-95% + 透明度0；ease-in；150-250ms

**适合**：删除、关闭模态框、消失

### 4. 转移退场（移向目标）

**技术**：向目标位置移动 + 缩放缩小；ease-in-out；250-400ms

**适合**：添加到购物车、保存到集合、移动到文件夹

---

## 入场退场连续性

- 眼睛自然跟随从退场到入场
- 尽可能使退场点靠近入场点
- 退场和入场之间100-150ms时机重叠
- 成对入场退场使用相同缓动系列

---

## 常见配方

### 通知滑入

```
1. 从右侧滑入 + 透明度（250ms, ease-out）
2. 过冲3-5%（企业）或10-15%（趣味）
3. 图标出现（100ms, 50ms延迟）
```

### Toast消失

```
1. 向边缘滑动 + 透明度（180ms, ease-in）
2. 剩余toast上移（200ms, ease-in-out）
```

### 下拉菜单打开

```
1. 缩放Y轴0→100%（200ms, ease-out）
2. 项目交错淡入（间隔30ms，容器后50ms）
```

### 页面转场（前进）

```
1. 当前页向左滑动 + 淡出（300ms, ease-in）
2. 新页面从右侧 + 淡入（400ms, ease-out, 100ms延迟）
3. 共享元素变形（400ms, ease-in-out）
```

### 卡片入场（Premium）

```
1. 开始：目标位置下方20px，透明度0
2. 路径：轻微曲线（中点X偏移10px）
3. 缓动：ease-out-cubic减速
4. 跟随通过：阴影在卡片后50ms到达
5. 次要：内容在卡片落地后100ms淡入
6. 分阶段：其他卡片变暗至80%
```

### 模态框入场

```
1. 背景：透明度0 → 50%（250ms, ease-out）
2. 模态框：从下方50px滑入 + 缩放95%→100%（350ms, ease-out）
3. 内容：交错淡入（间隔40ms，模态框后100ms）
```

## 入场退场时机参考

| 元素类型 | 入场 | 退场 |
|----------|------|------|
| 工具提示 | 150-200ms | 100-150ms |
| 下拉菜单 | 200-250ms | 150-200ms |
| 卡片 | 250-350ms | 150-250ms |
| 模态框 | 300-400ms | 200-300ms |
| 页面 | 400-600ms | 250-400ms |
| 全屏覆盖 | 400-600ms | 300-400ms |
