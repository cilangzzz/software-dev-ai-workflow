# 迪士尼12原则 — UI适配

## 1. 挤压与拉伸 (Squash and Stretch)
- 按压：scale ~[1.1, 0.9]
- 恢复：scale → 1.0
- 企业UI可跳过

## 2. 预备动作 (Anticipation)
- 主要动作前向相反方向小幅运动
- 持续时间：100-200ms
- 微反馈（<150ms）可跳过

## 3. 分场 (Staging)
- 非主角元素变暗至40-60%
- 每个时机节拍一个主要动作

## 4. 跟随通过 (Follow Through)
- 子元素延迟50-150ms
- 使用spring缓动

## 5. 缓入缓出 (Slow In and Slow Out)

| 上下文 | 缓动 |
|--------|------|
| 入场 | ease-out |
| 退场 | ease-in |
| 屏幕上 | ease-in-out |
| 循环 | sine ease-in-out |

**绝不对空间运动使用线性**

## 6. 弧线运动 (Arcs)
- 路径中点添加10-20px垂直偏移
- 企业风格微妙（5px），趣味风格明显（20px）

## 7. 次要动作 (Secondary Action)
- 幅度：主要的30-50%
- 时机：主要后50-100ms
- 示例：卡片入场 → 阴影增长

## 8. 时机 (Timing)

| 元素 | 持续时间 |
|------|----------|
| 模态框/页面 | 400-800ms |
| 工具提示/切换 | 100-250ms |

入场比退场长30-50%

## 9. 夸张 (Exaggeration)

| 个性 | 夸张程度 |
|------|----------|
| Playful | 15-25% |
| Energetic | 20-30% |
| Corporate | 0-5% |
| Premium | 0% |

## 10. 吸引力 (Appeal)
- 平滑曲线优于尖锐角度
- 避免：生硬运动、不一致时机、突然停止

---

## 组合示例

| 场景 | 原则组合 |
|------|----------|
| 按钮按压 | 预备 + 挤压拉伸 + 跟随通过 + 次要 |
| 卡片入场 | 预备 + 弧线 + 缓入缓出 + 跟随通过 |
| 成功状态 | 夸张 + 次要 + 时机 + 吸引力 |
| 错误抖动 | 时机 + 缓入缓出（无夸张） |
