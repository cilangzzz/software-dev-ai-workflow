# 多元素编排

## 基本原则

### 1/3规则

**距离规则**：运动不超过屏幕1/3无中间关键帧

**元素规则**：同时运动元素不超过总数1/3

### 交错策略

| 模式 | 延迟 | 总预算 | 用例 |
|------|------|--------|------|
| 微级联 | 20-40ms | <200ms | 列表项、网格 |
| 标准 | 50-100ms | <400ms | 卡片、导航 |
| 戏剧性 | 100-200ms | <600ms | 主角区块 |

**总交错时间必须 <500ms**

---

## 交错模式

### 线性交错
```javascript
stagger: 50 // 每项延迟50ms
```

### 中心扩展
```javascript
stagger: { each: 50, from: "center" }
```

### 边缘交错
```javascript
stagger: { each: 40, from: "start" } // 或 "end"
```

---

## 主角先行

- 主角最先开始或最突出
- 入场方向一致
- 非主角元素变暗（40-60%）

---

## 编排示例

### 仪表板入场
```
阶段1 (0-350ms): 主角图表
  - 从下方滑入（350ms）

阶段2 (100-450ms): 统计卡片
  - 交错50ms入场

阶段3 (300-500ms): 侧边栏
  - 淡入
```

### 下拉菜单
```
阶段1 (0-200ms): 容器
  - Y轴缩放0→100%

阶段2 (50-250ms): 菜单项
  - 交错30ms淡入
```
