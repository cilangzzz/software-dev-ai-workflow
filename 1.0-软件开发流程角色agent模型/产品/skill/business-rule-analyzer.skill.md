# Skill: business-rule-analyzer

## 基本信息
- **名称**: business-rule-analyzer
- **版本**: 1.0.0
- **所属部门**: 产品部
- **优先级**: P1

## 功能描述
从需求文档、用户故事或业务描述中提取、分析和结构化业务规则。生成完整的业务规则文档，包括规则编号、规则名称、规则描述、触发条件、约束条件等。

## 触发条件
- 命令触发: `/business-rule-analyzer`
- 自然语言触发:
  - "分析业务规则"
  - "提取业务规则"
  - "生成规则文档"
  - "梳理业务约束"

## 输入参数
| 参数名 | 类型 | 必填 | 描述 |
|--------|------|------|------|
| source | string | 是 | 需求文档或业务描述 |
| rule_prefix | string | 否 | 规则编号前缀，如 WO/INV/ORD |
| detail_level | string | 否 | 详细程度：summary/detailed |

## 执行流程
1. **需求解析** - 解析需求文档内容
2. **规则识别** - 识别显式和隐式业务规则
3. **规则分类** - 按类型分类规则（校验规则、约束规则、计算规则等）
4. **规则结构化** - 为每条规则分配编号和详细描述
5. **规则验证** - 检查规则完整性和一致性
6. **输出文档** - 生成业务规则文档

## 业务规则类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 校验规则 | 数据格式和有效性校验 | 手机号格式校验、金额非负校验 |
| 约束规则 | 业务操作约束条件 | 同一产线只能有一个生产中工单 |
| 计算规则 | 业务计算逻辑 | 订单金额=商品金额+运费-优惠 |
| 状态规则 | 状态流转规则 | 待下发→已下发→生产中→已完成 |
| 权限规则 | 操作权限约束 | 只有管理员可以审批 |
| 时间规则 | 时间相关约束 | 订单超过30分钟未支付自动取消 |
| 关联规则 | 数据关联约束 | 关闭工单前检查作业记录 |

### 3.1 校验规则

#### WO-001: 编号格式校验

| 属性 | 内容 |
|------|------|
| 规则编号 | WO-001 |
| 规则名称 | 编号格式校验 |
| 规则类型 | 校验规则 |
| 适用对象 | 工单编号(order_no) |
| 规则描述 | 工单编号必须符合指定格式：WO + 年月日 + 4位流水号 |
| 触发时机 | 创建工单时自动生成 |
| 校验逻辑 | 正则校验：^WO[0-9]{8}[0-9]{4}$ |
| 失败处理 | 系统自动生成，不会失败 |
| 优先级 | P0 |

**规则说明**：
工单编号由系统自动生成，格式为"WO"前缀 + 8位日期(YYYYMMDD) + 4位流水号。
示例：WO202603240001

**校验逻辑伪代码**：
```
FUNCTION generateOrderNo()
  dateStr = FORMAT(currentDate, "YYYYMMDD")
  seqNo = GET_NEXT_SEQUENCE("work_order_" + dateStr)
  orderNo = "WO" + dateStr + PAD(seqNo, 4, "0")
  RETURN orderNo
END FUNCTION
```

### 3.2 约束规则

#### WO-004: 产线唯一约束

| 属性 | 内容 |
|------|------|
| 规则编号 | WO-004 |
| 规则名称 | 产线唯一约束 |
| 规则类型 | 约束规则 |
| 适用对象 | 产线(line_id)、工单状态(status) |
| 规则描述 | 同一产线同一时间只能有一个"生产中"状态的工单 |
| 触发时机 | 开始生产时 |
| 校验逻辑 | 同一产线不存在其他"生产中"工单 |
| 失败处理 | 返回错误提示"该产线已有生产中的工单" |
| 优先级 | P0 |

**规则说明**：
为确保生产有序进行，同一产线在任意时刻只能有一个处于"生产中"状态的工单。
当尝试开始生产时，需检查该产线是否已有进行中的工单。

**校验逻辑伪代码**：
```
FUNCTION checkLineUnique(line_id)
  existingOrder = SELECT * FROM work_order 
                  WHERE line_id = line_id 
                  AND status = 2 -- 生产中
                  AND deleted = 0
  IF existingOrder EXISTS THEN
    RETURN ERROR("该产线已有生产中的工单[" + existingOrder.order_no + "]")
  END IF
  RETURN SUCCESS
END FUNCTION
```

### 3.3 状态规则

#### WO-007: 关闭前检查规则

| 属性 | 内容 |
|------|------|
| 规则编号 | WO-007 |
| 规则名称 | 关闭前检查规则 |
| 规则类型 | 状态规则 |
| 适用对象 | 作业记录(operation_record) |
| 规则描述 | 关闭工单前检查是否有未完成的作业记录 |
| 触发时机 | 关闭工单时 |
| 校验逻辑 | 不存在status=0(进行中)的作业记录 |
| 失败处理 | 返回错误提示"存在未完成的作业记录，请先处理" |
| 优先级 | P1 |

**规则说明**：
关闭工单前需检查关联的作业记录，确保所有作业都已完成或异常处理。
如果存在进行中的作业记录，需要先完成或终止这些作业才能关闭工单。

**校验逻辑伪代码**：
```
FUNCTION checkBeforeClose(work_order_id)
  pendingRecords = SELECT * FROM operation_record 
                   WHERE work_order_id = work_order_id 
                   AND status = 0 -- 进行中
                   AND deleted = 0
  IF pendingRecords EXISTS THEN
    RETURN ERROR("存在未完成的作业记录[" + pendingRecords[0].vin + "]，请先处理")
  END IF
  RETURN SUCCESS
END FUNCTION
```
