## 条件判断标准

### 项目规模判断

| 条件类型 | 判断标准 | 说明 |
|----------|----------|------|
| 小型项目 | 团队≤2人 且 周期≤2周 | 可简化产出物 |
| 中型项目 | 团队3-5人 或 周期2周-3个月 | 标准产出物 |
| 大型项目 | 团队>5人 或 周期>3个月 | 完整产出物+风险评估 |

### 技术复杂度判断

| 条件类型 | 判断标准 | 需要的产出物 |
|----------|----------|--------------|
| 单体应用 | 单一部署单元 | 架构图、数据库设计 |
| 微服务架构 | 多服务、多部署单元 | +模块划分、接口设计、数据流图 |
| 多系统集成 | 与外部系统交互 | +集成文档、数据流图 |
| 高并发系统 | QPS>1000 | +性能预测报告 |

### 团队协作判断

| 条件类型 | 判断标准 | 需要的产出物 |
|----------|----------|--------------|
| 个人开发 | 1人独立完成 | 可简化文档 |
| 小团队协作 | 2-3人协作 | 标准文档 |
| 多团队协作 | >3人或跨部门 | +模块划分、接口契约 |

## 产出物决策流程

```
开始项目
    │
    ├── 判断项目规模 ─────────────────────┐
    │   ├── 小型项目 → 简化产出物清单      │
    │   ├── 中型项目 → 标准产出物清单      │
    │   └── 大型项目 → 完整产出物清单      │
    │                                    │
    ├── 判断技术复杂度 ───────────────────┤
    │   ├── 单体应用 → 基础架构文档        │
    │   ├── 微服务 → +模块划分、接口设计   │
    │   └── 多系统集成 → +集成文档        │
    │                                    │
    └── 判断团队协作 ─────────────────────┤
        ├── 个人开发 → 可简化文档          │
        └── 多团队协作 → +接口契约文档     │
                                         │
                                         ↓
                              生成最终产出物清单
```
