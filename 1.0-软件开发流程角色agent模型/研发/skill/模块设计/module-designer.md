# Skill: module-designer

## 基本信息
- **名称**: module-designer
- **版本**: 1.0.0
- **所属部门**: 研发部
- **优先级**: P0

## 功能描述
根据需求文档和用户故事，生成详细的功能模块设计文档。包含功能清单、状态流转、数据模型、业务规则、接口设计、权限配置等完整模块设计内容。

## 触发条件
- 命令触发: `/module-designer`
- 自然语言触发:
  - "设计功能模块"
  - "生成模块设计文档"
  - "创建模块详细设计"
  - "设计业务模块"

## 输入参数
| 参数名 | 类型 | 必填 | 描述 |
|--------|------|------|------|
| module_name | string | 是 | 模块名称 |
| requirement_doc | string | 是 | 需求文档或用户故事 |
| system_context | string | 否 | 系统上下文信息 |
| priority | string | 否 | 优先级：P0/P1/P2，默认P1 |

## 执行流程
1. **需求解析** - 解析需求文档，识别核心功能点
2. **功能拆分** - 将需求拆分为具体功能项
3. **状态设计** - 设计业务状态流转
4. **数据建模** - 设计实体和数据库表结构
5. **规则定义** - 定义业务规则和约束
6. **接口设计** - 设计RESTful API接口
7. **权限配置** - 定义操作权限标识
8. **用户故事映射** - 生成模块相关的用户故事

## 使用示例

### 示例1：设计库存管理模块

**输入**:
```
模块名称: 库存管理
需求描述:
- 管理仓库库存信息
- 支持入库、出库操作
- 库存预警功能
- 库存盘点功能
- 支持多仓库管理
```

**输出**:

```
### 状态定义

| 状态值 | 状态名 | 说明 | 允许操作 |
|--------|--------|------|----------|
| 0 | 待入库 | 物料待入库 | 入库 |

## 业务规则

| 规则编号 | 规则名称 | 规则描述 |
|----------|----------|----------|
| INV-001 | 库存非负 | 库存数量不可为负数 |
| INV-002 | 可用校验 | 出库数量不可超过可用数量 |
| INV-003 | 预警规则 | 库存低于安全库存时触发预警 |
| INV-004 | 批次管理 | 启用批次管理时必须填写批次号 |
| INV-005 | 库位唯一 | 同一仓库同一库位只能存放一个SKU |
```
